# Rank-one support forces a strong-channel overlap floor

Status: **rigorous obstruction on the exact actual-child law; independently
audited**.  The raw
negative-window overlap cannot vanish for all fixed temperatures.  Above an
explicit covering threshold, every pair of actual contracted-temperature
children has a fixed positive overlap density throughout a nonzero interval
of negative disorder tilts.  The proof uses the exact child-induced
rank-one channel, not a conference or other surrogate.  It does not use
pressure minimality beyond selecting the children: the obstruction comes
from the fact that `Theta(N^2)` bridge observations are generated by only
`O(N)` latent bits.

## 1. Exact channel and support count

Fix children of orders `m,n`, put `N=m+n`, `d=mn`, and let
`t=beta/sqrt(N)`, `rho=tanh t`.  For either orientation, the zero-bridge
augmented child Gibbs law induces a law `mu` on

```math
Q=(Q_{ij})=(\tau X_iY_j)\in\{-1,1\}^{m\times n}.
```

The bridge pressure has the exact presentation

```math
L(B)=c+\log E_\mu e^{t\langle B,Q\rangle},          \tag{RSO.1}
```

where `c` is independent of `B`.  Although `(tau,X,Y)` has `N+1` signs,
`tau` can be absorbed into `X`, and `(X,Y)` and `(-X,-Y)` give the same
rank-one matrix.  Therefore

```math
K:=|\operatorname {supp}\mu|\le 2^{N-1}.             \tag{RSO.2}
```

For `s<=0`, let

```math
dq_s={e^{sL}\over E_Ue^{sL}}dU.                     \tag{RSO.3}
```

This is exactly the raw law `widehat Pi_s` in Theorem 37.50.

Delete bridge edge `e`.  If

```math
r_e(B_{-e})=E[Q_e\mid B_{-e}]                       \tag{RSO.4}
```

under the positive child channel and
`m_e(B)=E[Q_e|B]` is the full posterior response, then

```math
m_e={r_e+\rho B_e\over1+\rho B_er_e}.                \tag{RSO.5}
```

Thus (RSO.4) is exactly the edge-cavity response used in the definition of
`widehat rho_N^-`.

## 2. A pointwise posterior-energy inequality

Conditionally on `B_{-e}`, (RSO.1) and (RSO.3) give

```math
E_{q_s}[B_e\mid B_{-e}]
=\tanh\!\left(s\operatorname {arctanh}(\rho r_e)\right).       \tag{RSO.6}
```

The algebraic identity

```math
B_em_e=B_er_e+{\rho(1-r_e^2)\over1+B_e\rho r_e}      \tag{RSO.7}
```

therefore yields

```math
E_{q_s}[B_em_e\mid B_{-e}]
=r_e\tanh\!\left(s\operatorname {arctanh}(\rho r_e)\right)
 +\rho(1-r_e^2)E_{q_s}\left[{1\over1+B_e\rho r_e}
                         \middle|B_{-e}\right].      \tag{RSO.8}
```

Fix `delta>0`.  For `s in [-delta,0]`, use

```math
|\tanh(sz)|\le |s z|,
\qquad
\operatorname {arctanh}(\rho|r|)
 \le {\rho|r|\over1-\rho^2},
\qquad
{1\over1+B\rho r}\ge {1\over1+\rho}.
```

Writing

```math
A_\rho={1\over1+\rho},
\qquad
C_{\rho,\delta}=A_\rho+{\delta\over1-\rho^2},       \tag{RSO.9}
```

gives the uniform conditional lower bound

```math
E_{q_s}[B_em_e\mid B_{-e}]
\ge\rho\{A_\rho-C_{\rho,\delta}r_e^2\}.             \tag{RSO.10}
```

Put

```math
S_s=E_{q_s}\sum_e r_e^2,
\qquad
X(B)=\max_{Q\in\operatorname {supp}\mu}\langle B,Q\rangle.
```

Pointwise,

```math
\sum_eB_em_e(B)=E[\langle B,Q\rangle\mid B]\le X(B).            \tag{RSO.11}
```

Summing (RSO.10), taking expectations, and applying (RSO.11) proves

```math
\boxed{
{S_s\over d}\ge {1\over C_{\rho,\delta}}
 \left\{A_\rho-{E_{q_s}X\over\rho d}\right\}.}     \tag{RSO.12}
```

## 3. The support-entropy bound

A one-bit flip changes `L` by at most `2t`; marginalization preserves this
oscillation.  Hence every conditional bit of `q_s` has half-log-odds at
most `|s|t`.  The KL chain rule gives the sharper bound

```math
D(q_s\Vert U)
\le d\,\kappa(|s|t)
\le {|s|^2t^2d\over2},                              \tag{RSO.13}
```

where `kappa(a)=a tanh a-log cosh a` and
`kappa(a)<=a^2/2` follows by integration of
`kappa'(a)=a sech^2a<=a`.

For every `theta>0`, the union bound and the Rademacher MGF give

```math
\log E_Ue^{\theta X}
\le\log K+d\log\cosh\theta
\le\log K+{d\theta^2\over2}.                       \tag{RSO.14}
```

Donsker--Varadhan transport, optimized in `theta`, now gives

```math
E_{q_s}X
\le\sqrt{2d\{\log K+D(q_s\Vert U)\}}.              \tag{RSO.15}
```

Equations (RSO.2), (RSO.12), (RSO.13), and (RSO.15) are finite-order and
hold for every actual child pair.  In particular, uniformly for
`s in [-delta,0]`, they give the explicit finite bound

```math
\boxed{
{S_s\over d}\ge {1\over C_{\rho,\delta}}
\left\{A_\rho-
 \sqrt{{2\{(N-1)\log2+d\kappa(\delta t)\}\over\rho^2d}}
\right\}.}                                           \tag{RSO.16}
```

## 4. Explicit asymptotic overlap floor

Assume comparable splits with

```math
{mn\over N^2}\ge\gamma_0>0                         \tag{RSO.17}
```

for all large `N`, and suppose

```math
\boxed{\beta^2\gamma_0>2\log2.}                    \tag{RSO.18}
```

Choose

```math
0<\delta<\min\left\{\lambda,1,
 \sqrt{1-{2\log2\over\beta^2\gamma_0}}\right\}.  \tag{RSO.19}
```

Uniformly for `s in [-delta,0]`, (RSO.12)--(RSO.15),
`rho/t->1`, and `A_rho->1` imply

```math
\liminf_{N\to\infty}{S_s\over mn}
\ge c_{\beta,\gamma_0,\delta}
:={1-\sqrt{2\log2/(\beta^2\gamma_0)+\delta^2}
   \over1+\delta}>0.                                \tag{RSO.20}
```

Since

```math
\widehat\rho_N^-(\lambda)
={1\over\lambda mn}\int_{-\lambda}^0S_s\,ds,
```

Fatou's lemma gives the obstruction

```math
\boxed{
\liminf_{N\to\infty}\widehat\rho_N^-(\lambda)
\ge {\delta\over\lambda}
 c_{\beta,\gamma_0,\delta}>0.}                     \tag{RSO.21}
```

For balanced splits, `gamma_0=1/4`, so the explicit threshold is

```math
\beta>\sqrt{8\log2}=2.354820\ldots.                 \tag{RSO.22}
```

## 5. Scope and consequence

The theorem does not identify which part of the positive cavity response is
row-additive and which part is irreducible reverse-product dependence.  It
does prove that the current SML, stated as
`widehat rho_N^-(lambda)=o(1)` for arbitrary fixed target-reaching `beta`,
is false above (RSO.18), even on the exact optimizing-child law.

The obstruction is not a high-order cumulant surrogate.  It is the exact
rank-one latent support of the actual channel: a family of at most
`2^(N-1)` planted bridge words cannot cover the `2^(Theta(N^2))` bridge cube
at the physical signal strength once (RSO.18) holds.  Any surviving
Level-6 use of negative-disorder overlap must therefore subtract the
response explainable by this low-rate latent support, or exploit a
renormalized rare-event object rather than demand raw overlap decay.
