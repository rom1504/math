# The exact Fourier feature algebra of Boolean ports

**Status.** Rigorous theorem with an exact finite verifier.  This note treats
the labelled linear response of a family of Boolean ports.  It identifies its
minimal exact contextual state, its composition law, and the first port count
at which Gram data cease to be sufficient.  It does not include a quadratic
old-spin energy; the regular-Hadamard collision is a separate strengthening.

## 1. Labelled port responses

Let `W in {+-1}^{n times p}` and write its columns as Boolean ports
`w_1,...,w_p`.  For an endpoint word `epsilon in {+-1}^p`, define

```math
L_W(epsilon)
=\max_{x\in\{+-1\}^n}\sum_{i=1}^p
     \epsilon_iw_i^Tx
=\|W\epsilon\|_1.                                  \tag{PF.1}
```

Changing the sign of a row of `W` does not change this table.  Let

```math
G_p=\{+-1\}^p/\{s\sim-s\}                         \tag{PF.2}
```

be the projective Boolean group, and let `mu_W(g)` count the rows of `W`
with projective type `g`.  Put

```math
g_p(z)=\left|\sum_{i=1}^pz_i\right|.               \tag{PF.3}
```

Then the response table is the group convolution

```math
L_W(epsilon)=\sum_{s\in G_p}\mu_W(s)g_p(s\epsilon).
                                                               \tag{PF.4}
```

## 2. Every projective Fourier channel is visible

Characters of `G_p` are indexed by even subsets `S subseteq [p]`:

```math
\chi_S(z)=\prod_{i\in S}z_i.                       \tag{PF.5}
```

Let `P=2 ceil(p/2)`.  With normalized Fourier coefficients, direct binomial
summation gives

```math
\widehat g_p(\varnothing)
={ (P-1)!!\over(P-2)!!},                           \tag{PF.6}
```

and, for `|S|=2k>=2`,

```math
\boxed{
\widehat g_p(S)
=(-1)^{k-1}{(2k-3)!!(P-2k-1)!!\over(P-2)!!}.}     \tag{PF.7}
```

Here `(-1)!!=0!!=1`.  In particular every multiplier is nonzero.

### Theorem PF.1 (exact port-response state)

For Boolean port systems `W,W'` with the same row count, the following are
equivalent:

1. `L_W(epsilon)=L_(W')(epsilon)` for every endpoint word;
2. `mu_W=mu_(W')` on `G_p`;
3. after permuting rows and independently changing row signs, `W=W'`.

Consequently the exact contextual quotient of unordered `n`-row Boolean
port systems under all labelled endpoint queries has

```math
\boxed{{n+2^{p-1}-1\choose 2^{p-1}-1}}             \tag{PF.8}
```

states.  Under disjoint-row composition its minimal state closes by

```math
\mu_{W\sqcup V}=\mu_W+\mu_V,
\qquad L_{W\sqcup V}=L_W+L_V.                      \tag{PF.9}
```

The same state answers every real weighted port query, not only Boolean
endpoints:

```math
L_W(a)=\|Wa\|_1
=\sum_{s\in G_p}\mu_W(s)|s\cdot a|
\qquad(a\in\mathbb R^p).                           \tag{PF.9a}
```

Thus the finite Boolean query language already identifies the complete
centrally symmetric zonotope support function generated by the rows.

Thus the full projective row histogram is an exact commutative feature
algebra.  It is much smaller than a labelled microscopic row list, but it
has `2^(p-1)-1` independent coordinates; no exact quotient can discard one
of them while retaining every labelled future response.

#### Proof

Equation (PF.4) gives, for every even `S`,

```math
\widehat L_W(S)=|G_p|\widehat\mu_W(S)\widehat g_p(S)             \tag{PF.10}
```

under the normalized-convolution convention.  Formula (PF.7) makes every
multiplier nonzero, so Fourier inversion proves `1 iff 2`.  Projective row
types are exactly the row orbits under sign and permutation, proving
`2 iff 3`.  Weak compositions of `n` into `|G_p|=2^(p-1)` parts are counted
by (PF.8), and concatenation proves (PF.9).

For completeness, (PF.6)--(PF.7) follow from

```math
2^{-p}\sum_{z\in\{+-1\}^p}
 \left|\sum_i z_i\right|\chi_S(z).                 \tag{PF.11}
```

If `p` is odd, adjoining one unused Rademacher coordinate does not change
the coefficient because the old sum is odd and
`(|a+1|+|a-1|)/2=|a|`; hence it is enough to take even `P`.  Grouping the
`P` signs by their number of minuses and applying Pascal's identity twice
gives, successively,

```math
\widehat g_P(\varnothing)={(P-1)!!\over(P-2)!!},
```

```math
{\widehat g_P(2k)\over\widehat g_(P-2)(2k)}
={P-2k-1\over P-2}\quad(2k<P),                    \tag{PF.12}
```

and the terminal alternating sum

```math
\widehat g_(2k)(2k)
=(-1)^{k-1}{(2k-3)!!\over(2k-2)!!}.                \tag{PF.13}
```

Iteration proves (PF.7). `square`

### Theorem PF.2 (fixed-error sparse response coresets)

Normalize the contextual response metric by

```math
d_p(\mu,\nu)
=\max_{\epsilon\in G_p}
 \left|\mathbb E_\mu{g_p(s\epsilon)\over p}
       -\mathbb E_\nu{g_p(s\epsilon)\over p}\right|.          \tag{PF.15}
```

For every probability measure `mu` on `G_p` and `0<eta<1`, there is an
equally weighted measure `nu` on at most

```math
K=\left\lceil{p\log2+\log2\over2\eta^2}\right\rceil           \tag{PF.16}
```

projective row types such that `d_p(mu,nu)<=eta`.  Consequently the whole
response image has an explicit cover satisfying

```math
\log\operatorname {Cov}(\eta)
\le K(p-1)\log2
=O(p^2/\eta^2).                                    \tag{PF.17}
```

Conversely, for every fixed `0<theta<1/2`, the point-mass port systems
contain

```math
2^{(1-H_2(\theta)-o(1))p}                          \tag{PF.18}
```

states pairwise separated by `2theta` in `d_p`.  Thus fixed-error Boolean
port response complexity is at least linear and at most quadratic in `p`
bits, despite the exact feature dimension being exponential.

#### Proof

Draw `K` independent row types from `mu`.  For each fixed endpoint query,
`g_p/p` lies in `[0,1]`, so Hoeffding's inequality and a union bound over
`|G_p|=2^(p-1)` queries make all empirical means `eta`-accurate with positive
probability when (PF.16) holds.  Encoding the ordered sample gives at most
`|G_p|^K` centres, proving (PF.17).

For point masses, let `h(s,t)<=p/2` be projective Hamming distance.  The
reverse triangle inequality gives

```math
d_p(\delta_s,\delta_t)\le {2h(s,t)\over p},         \tag{PF.19}
```

and equality follows by querying `epsilon=s`.  A greedy projective Hamming
code of relative distance `theta` proves (PF.18). `square`

The upper bound is the classical empirical-method/Hoeffding mechanism.  The
dimension-free Rademacher argument in
`boolean_port_dimension_free_coreset.md` sharpens (PF.16) to

```math
K=\lceil16/\eta^2\rceil,
\qquad
\log\operatorname {Cov}_p(\eta)=\Theta_\eta(p)     \tag{PF.20}
```

for every fixed `eta<1/2`, closing the static fixed-scale rate.  The
compositional limitation remains important: convexly mixing already-built
coresets preserves their errors, but resparsifying after every merge adds a
fresh error.  Neither sampling theorem is by itself an all-depth dynamic
congruence.  A reusable merge-reduce law with bounded cumulative error
remains open.

## 3. Gram is exactly the first Fourier truncation

The port Gram matrix is

```math
(W^TW)_{ij}=\sum_s\mu_W(s)s_is_j.                  \tag{PF.14}
```

It therefore records precisely the total mass and the degree-two
projective Fourier coefficients of `mu_W`.  For `p<=3` these are all even
characters, so Gram data determine the entire labelled response table.
For `p=4`, the unresolved degree-four parity coefficient is the first
possible collision.

The two systems in `four_port_gram_boolean_collision.md` realize it:
uniform rows and doubled even-parity rows have the same Gram matrix, while
their maximum joint supports are `3n/2` and `2n`.  Hence four ports are
minimal for a pure-linear equal-Gram Boolean response collision.

## 4. Interpretation

This theorem separates three claims which are easy to conflate:

1. a fixed number of ports has a finite-dimensional exact state;
2. Gram data are a sufficient exact state;
3. that state remains small when the number of ports grows.

Only the first is true.  The correct exact state is algebraically closed
under disjoint composition, but its dimension is exponential in the port
count.  Approximate compression can still be smaller because the Fourier
multipliers in (PF.7) decay away from endpoint degrees; determining the
uniform response rate--distortion of this convolution image is a separate
question.

The theorem also explains why fourth-order row-pattern information, rather
than another quadratic Gram correction, is forced by the four-port
collision.  Once a quadratic child is added, its correlation with those row
types may require still richer joint data; the theorem makes no sufficiency
claim for that interacting problem.
