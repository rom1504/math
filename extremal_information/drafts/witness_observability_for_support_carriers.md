# Witness observability for weighted anticipatory supports

**Status.** Proof draft.  This note identifies a nontrivial condition under
which a support phase is not merely proof memory: a small declared family of
rooted futures exposes it in the response metric.  The condition couples the
backward-surjective supports of Theorem 17.1s to a forward endpoint envelope.
Neither half alone is enough.

The main result is not an arbitrary-lookup theorem.  Its probe family is the
orbit of one bounded readout under a presented permutation action.  In the
deterministic de Bruijn example, two navigation letters (cyclic rotation and
its inverse) and one readout of the first symbol expose all `q^m` phases.

## 1. Rooted responses and gap filtering

Let `I` and `E` be finite.  For each `e in E`, let `T_e` be a max-plus matrix
and let `lambda_e in R`.  Assume

```math
T_e(i,j)\le lambda_e.                                         \tag{WO.1}
```

All statements use one fixed gauge.  Unlike a word spectral radius, a rooted
response with flat initial weights is not gauge-invariant unless its initial
and terminal potentials are transformed contragrediently.  Thus the declared
root convention is part of the interface and cannot be changed mid-theorem.

Fix `theta_e>=0` and define a good-edge relation

```math
R_e=\{(i,j):T_e(i,j)\ge lambda_e-theta_e\}.                   \tag{WO.2}
```

Assume there is a uniform gap `C>0` such that

```math
(i,j)\notin R_e\quad\Longrightarrow\quad
T_e(i,j)\le lambda_e-C,                                       \tag{WO.3}
```

with `-infinity` allowed.  For a word `u=e_1...e_t`, write

```math
Lambda(u)=\sum_s lambda_(e_s),\qquad
Theta(u)=\sum_s theta_(e_s),
```

and, for a nonempty root set `A subseteq I`, let

```math
A_u=R_u(A)                                                     \tag{WO.4}
```

be the set of endpoints of all-good paths.  For a terminal field
`f:I->R`, define the toll-normalized rooted response

```math
V_A(u;f)=
\max_{i\in A,\ j\in I}\{T_u(i,j)+f(j)\}-Lambda(u).            \tag{WO.5}
```

This is a declared rooted query.  It differs from the unrooted spectral
response: the left endpoint is restricted to the current root set and a
terminal field may inspect the endpoint.

For a general coarse system in Theorem 17.1s, fix a coarse path and regard
its finite edges `c=(a,e,b)` as the alphabet, with toll
`lambda_c=S_e(a,b)`.  The results below then apply verbatim to the response
rooted on that coarse path.  Maximizing over several coarse paths can erase
the phase again and requires a separate exposure condition.

### Theorem WO.1 (uniform-gap endpoint filtering)

Suppose `A_u` is nonempty and

```math
Theta(u)+osc(f)<C.                                             \tag{WO.6}
```

Then

```math
\max_{j\in A_u}f(j)-Theta(u)
\le V_A(u;f)\le
\max_{j\in A_u}f(j).                                          \tag{WO.7}
```

In the exact case `theta_e=0`,

```math
\boxed{V_A(u;f)=\max_{j\in A_u}f(j)}.                         \tag{WO.8}
```

#### Proof

Every all-good path has weight in
`[Lambda(u)-Theta(u),Lambda(u)]`.  Choosing an all-good path to
an endpoint maximizing `f` proves the lower bound in (WO.7), and every
all-good path satisfies the upper bound.

A path using a nongood edge has weight at most `Lambda(u)-C`.  Its score is
therefore at most

```math
Lambda(u)-C+max_I f
<Lambda(u)-Theta(u)+min_I f,
```

which is no larger than the score of some all-good path.  Thus a nongood path
cannot optimize.  At `Theta(u)=0`, all good paths have exactly the declared
toll, giving (WO.8). `square`

The strict inequality in (WO.6) can be replaced by `<=` without changing the
value, at the price of allowing ties with defective paths.  The strict form
is more useful when the maximizing witness itself matters.

## 2. One readout orbit gives the exact declared response metric

Let a finite group `G` act on `I` by permutations and fix one bounded readout
`r:I->R`.  Put

```math
W=osc(r),\qquad r_g(i)=r(g i),

Phi_r(B)(g)=\max_{i\in B}r_g(i)\quad(B\ne emptyset).            \tag{WO.9}
```

The declared terminal probes are `k r_g`, `g in G`.  They are generated by
one readout and a navigation action, rather than by a lookup table indexed by
raw states.  Equivalently, `k r` is realized by repeating `k` times the
diagonal probe matrix

```math
P_r(i,j)=cases(r(i),&j=i; -infinity,&j!=i),                    \tag{WO.10}
```

after a hard permutation word realizing `g`.

A rooted response summary on a history family `H` is a map `z:H->Z` and a
decoder `D:Z times G->R`.  At probe multiplicity `k`, its uniform error is

```math
\sup_{u\in H,g\in G}|D(z(u),g)-V_A(u;k r_g)|.                 \tag{WO.10a}
```

For a sequential implementation of `g` followed by `p^k`, replace the right
side by the permitted error as a function of the future-word length.  The
packing statements below use no restriction on the decoder: if two histories
share one state, it must return the same answer to their common future.

### Corollary WO.2 (probe-profile isometry)

In the exact case, for `kW<C`,

```math
V_A(u;k r_g)=k Phi_r(A_u)(g),                                 \tag{WO.11}
```

and hence for two histories `u,v` with nonempty tight endpoint sets,

```math
\sup_{g\in G}|V_A(u;k r_g)-V_A(v;k r_g)|
=k\|Phi_r(A_u)-Phi_r(A_v)\|_infinity.                         \tag{WO.12}
```

Thus equality of the orbit-max profiles is necessary and sufficient for
contextual equivalence under this declared probe family.  If `M` histories
have profiles pairwise separated by `gamma`, every summary answering all
these rooted futures to absolute error less than `k gamma/2` has at least
`M` states.

With nonzero `theta_e`, the two sides of (WO.12) differ by at most
`Theta(u)+Theta(v)`, provided

```math
max\{Theta(u),Theta(v)\}+kW<C.                                \tag{WO.13}
```

#### Proof

Apply Theorem WO.1 to `f=k r_g`.  The exact identity gives (WO.11) and
(WO.12).  In the approximate case each response differs from the displayed
profile value by a number in `[-Theta,0]`.  The packing claim is the triangle
inequality: two histories represented by one summary state would have
response distance less than twice its error. `square`

In the exact case, projective response is handled by adjoining the zero
terminal field.  It anchors one coordinate of every profile.  A
`gamma`-separated absolute profile family is then at least `gamma/2`-separated
modulo constants, so the corresponding projective error threshold is
`k gamma/4`.

## 3. When an anticipatory support phase is observable

For an exact scalar Theorem-17.1s carrier, restrict first to the nonempty set
of supports having maximal support potential.  It is closed under every
letter: from a maximal-potential support, `beta=0`, `d>=0`, and
`d<=psi(K')-psi(K)` force `d=0` and `psi(K')=psi(K)`.  Thus this tight core
has a deterministic phase system `(Q,delta)` and nonempty supports
`K_q subseteq I` satisfying

```math
K_(delta(q,e)) subseteq R_e(K_q).                              \tag{WO.14}
```

More generally, (WO.14) may simply be assumed for a chosen good-edge
relation in an approximate carrier.  It is backward-surjective: every
selected future endpoint has a selected predecessor.  It does not control
extra forward endpoints.  Introduce
nonempty **forward envelopes** `B_q` satisfying

```math
K_q subseteq B_q,
\qquad R_e(B_q) subseteq B_(delta(q,e)).                       \tag{WO.15}
```

Finally impose probe saturation:

```math
\max_{i\in K_q}r_g(i)=\max_{i\in B_q}r_g(i)
\qquad(q\in Q,\ g\in G).                                     \tag{WO.16}
```

The special case `B_q=K_q`, equivalently
`R_e(K_q)=K_(delta(q,e))`, is a bi-exact subset carrier.

### Theorem WO.3 (observable support sandwich)

Fix a start phase `q_0` and root set `A=K_(q_0)`.  After a history `u`, put
`q_u=delta(q_0,u)`.  Under (WO.14)--(WO.16),

```math
K_(q_u) subseteq A_u subseteq B_(q_u),

Phi_r(A_u)=Phi_r(K_(q_u))=Phi_r(B_(q_u)).                      \tag{WO.17}
```

Consequently, if all reachable phase profiles
`Phi_r(K_q)` are pairwise `gamma`-separated, they form an intrinsic rooted
response packing of the same cardinality.  In the exact weighted system and
for `kW<C`, error below `k gamma/2` requires one response state per reachable
phase.  Under (WO.13), replace `k gamma` by
`k gamma-Theta(u)-Theta(v)`.

#### Proof

The lower inclusion follows inductively from (WO.14): if
`K_q subseteq A_u`, then

```math
K_(delta(q,e)) subseteq R_e(K_q) subseteq R_e(A_u).
```

The upper inclusion follows similarly from (WO.15).  Taking maxima of every
`r_g` over the sandwich and using (WO.16) proves (WO.17).  Corollary WO.2
then gives the response packing. `square`

The carrier inclusions are generator-checkable once `Q,K,B` are presented.
Probe saturation is a finite orbit condition.  It can be certified
structurally from a local code, as in Section 4, but for an arbitrary
black-box permutation group its check may still be output-sensitive.  No
input-word products or complete weighted orbit language are needed.  The
conditions isolate the exact missing datum:

- a rowwise lift is source-total but need not retain an endpoint phase;
- an anticipatory support is target-surjective but may ignore extra forward
  endpoints;
- the observable sandwich couples both directions only up to what the
  declared probes can see.

Thus forward/path and anticipatory certificates remain incomparable.  A
probe-visible bi-exact carrier is a stronger, genuinely response-bearing
object, not a consequence of either certificate alone.

## 4. Deterministic de Bruijn: one local probe exposes every phase

Let `E={0,...,q-1}`, `I=E^m`, and

```math
F_e(s_1...s_m)=s_2...s_me,

T_e(s,t)=cases(0,&t=F_e(s); -C,&t!=F_e(s)).                   \tag{WO.18}
```

The tight singleton supports form the bi-exact carrier

```math
K_s=B_s=\{s\},\qquad delta(s,e)=F_e(s).                       \tag{WO.19}
```

Let `G` be the cyclic coordinate-rotation group and take the local readout

```math
r(s)={s_1\over q-1}.                                          \tag{WO.20}
```

It has `W=1`.  Its rotation profile lists all symbols of `s`, so two distinct
windows have profile distance at least

```math
gamma={1\over q-1}.                                           \tag{WO.21}
```

Every window is reached from every start after the length-`m` input word
which names it.

### Corollary WO.4 (local-probe de Bruijn packing)

For every `1<=ell<=m` and every integer `1<=k<C`, the `q^ell`
length-`ell` histories have rooted response distance at least

```math
{k\over q-1}                                                   \tag{WO.22}
```

under the futures generated by cyclic rotation and `k` repetitions of the
single first-symbol probe.  Hence absolute error below
`k/[2(q-1)]` requires `q^ell` response states; at `ell=m` this is `q^m`.

If the nontight entries in (WO.18) are changed to `-infinity`, `k` is
unrestricted.  A predictor with error at most `epsilon` per repeated probe
plus a fixed additive constant therefore needs `q^m` states whenever

```math
epsilon<{1\over2(q-1)}.                                       \tag{WO.23}
```

For the all-finite family `C=m`, choosing `k=floor((m-1)/2)` gives a
`Theta(m)` response packing from a fixed-size probe alphabet.  With rotation
and inverse rotation as navigation letters, access length is at most `m/2`.
Thus a future-normalized predictor with sublinear additive slack still needs
`q^m` states below asymptotic error `1/[4(q-1)]` (with any strict margin).

#### Proof

For a word `u` of length at most `m`, its tight endpoint set consists of all
windows ending in `u`; every other endpoint is available only at loss `C`.
If two equal-length words differ in their `j`th symbol, rotate that suffix
coordinate to coordinate one.  The readout is constant on each of the two
tight endpoint sets and differs by at least `1/(q-1)`.  Corollary WO.2 gives
(WO.22).

For hard deterministic edges there is no leakage, so let `k` tend to
infinity and divide the two predictor error inequalities by `k`.  In the
all-finite scaling, the distinguishing future has length at most
`m/2+floor((m-1)/2)<=m`, while its response gap is asymptotic to
`m/[2(q-1)]`.  The usual merged-state triangle inequality gives the final
threshold. `square`

This does not contradict the one-state rowwise lift in Theorem 18.5.  That
lift preserves unrooted word spectra.  It does not preserve which tight
endpoint the history reaches, and the new rooted probes ask exactly that
question.

## 5. The finite-gap ceiling

The restriction `kW<C` is substantive, not a proof artifact.  In the
all-finite de Bruijn system, for a length-`m` word `u`,

```math
T_u(I,t)=cases(0,&t=u; -C,&t!=u).                              \tag{WO.24}
```

Therefore, after any navigation permutation `g`,

```math
V_I(u;k r_g)=
\max\{k r_g(u),\ -C+k\max_(t!=u)r_g(t)\}.                    \tag{WO.25}
```

For fixed `m,C` and `k->infinity`, every history has limiting probe rate
`max_I r`; history differences remain bounded by `C`.  A finite defect can
eventually buy entry to the best probe-rate state.

This ceiling is not special to the diagonal probe.  Let
`z_u(t)=max_(i in I)T_u(i,t)`.  For length-`m` histories,

```math
z_u(t)=0\ (t=u),\qquad z_u(t)=-C\ (t\ne u),

\|z_u-z_v\|_infinity=C\quad(u\ne v).                          \tag{WO.26}
```

Every common max-plus continuation and terminal maximum is one-Lipschitz in
the sup norm.  Hence **no** common future can separate two such all-finite
root vectors by more than `C`, regardless of its length.  It can expose a
macroscopic phase only when `C` itself is macroscopic; it can never create a
fixed-`m` asymptotic rate gap.

Hence no theorem can turn finite-gap anticipatory memory into an
infinite-horizon rate packing without one of the following additional data:

1. hard reachability (`-infinity` leakage);
2. a phase-preserving reset or filter;
3. a probe horizon whose total oscillation is below the gap; or
4. a rooted semantics which conditions on the actual endpoint rather than
   carrying every finitely penalized alternative.

This is the ceiling on witness observability.  Theorem WO.3 is strong but not
tautological: its probe family may have a constant-size generator
description, while its saturation condition is a finite two-sided
reachability check.  As always, the description length of `r` and of the
navigation generators must be charged.  Choosing an arbitrary lookup table
as `r` would merely move the hidden state into the query and is not claimed
as compression.  The de Bruijn readout (WO.20) is one local coordinate
function and the navigation group has two local generators.  What cannot be
inferred from support count alone is precisely forward attainability and
probe exposure.
