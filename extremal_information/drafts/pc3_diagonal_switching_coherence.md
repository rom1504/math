# PC.3 diagonal switchings cannot hide coherent selector loss

**Status.**  Rigorous scalable no-go theorem for the complete diagonal-
switching class of the PC.3 tensor regular-Hadamard family, with exact
finite verifier at orders `256` and `4096`.

The exact-sign five-port seed shows that fixed marginal Rayleigh loss can
coexist with a larger coherent majority loss.  The weighted contraction
example shows the same phenomenon with vanishing marginal loss.  This note
closes the most natural route from the former to the latter: **no diagonal
switching of the growing PC.3 tensor family can have vanishing active-product
deficits and a nonvanishing selector deficit.**  In fact every selector
deficit is at most twice the average product deficit, at every tensor depth.

This is a theorem about the prescribed same-field selector certificate.  It
does not compare full Boolean trust optima, and it does not cover arbitrary
exact-sign perturbations unrelated to diagonal switching.

## 1. A gapped twirl lemma

For a Boolean vector `v`, write `M_v=diag(v)`.  Let `T` be a real symmetric
contraction on `R^n`, let `Z` be a nonempty finite set of Boolean vectors,
and define

```math
B_z=M_zTM_z,
\qquad
K={1\over |Z|}\sum_{z\in Z}B_z,
\qquad
\overline D=I-K.                                  \tag{DS.1}
```

Every `B_z` and `K` is a symmetric contraction, so `I-B_z` and
`\overline D` are positive semidefinite.

### Lemma DS.1 (span-to-coherence through a gapped twirl)

Suppose

```math
\operatorname {spec}(K)\subseteq[-1,1-\gamma]\cup\{1\}
\quad\hbox{for some }\gamma>0.                    \tag{DS.2}
```

If `x in {+-1}^n` lies in the real linear span of `Z`, then

```math
\boxed{
I-M_xTM_x\preceq {2\over\gamma}\overline D.}      \tag{DS.3}
```

Consequently, for every real vector `s` with `||s||_2^2=n`,

```math
1-{s^TM_xTM_xs\over n}
\le {2\over\gamma|Z|}
 \sum_{z\in Z}\left(1-{s^TM_zTM_zs\over n}\right). \tag{DS.4}
```

#### Proof

Put `E=ker(I-K)`.  Since

```math
I-K={1\over|Z|}\sum_{z\in Z}(I-B_z)
```

is an average of positive semidefinite matrices,

```math
E=\bigcap_{z\in Z}\ker(I-B_z).                   \tag{DS.5}
```

Thus, for `u in E` and every `z in Z`,

```math
T(M_zu)=M_zu.                                     \tag{DS.6}
```

Write `x=sum_z a_z z`.  Pointwise multiplication and linearity give

```math
T(M_xu)=\sum_z a_zT(M_zu)
       =\sum_z a_zM_zu=M_xu.                     \tag{DS.7}
```

Because `x` is Boolean, multiplying once more by `M_x` shows
`M_xTM_xu=u`.  Therefore `I-M_xTM_x` annihilates `E`.  This matrix is
positive semidefinite and has operator norm at most two.  If `P` is the
orthogonal projection onto `E^perp`, then

```math
0\preceq I-M_xTM_x\preceq2P,
\qquad
\overline D\succeq\gamma P                       \tag{DS.8}
```

by (DS.2).  This proves (DS.3); evaluating its quadratic form at `s` and
expanding (DS.1) proves (DS.4). `square`

The content is not a separate-channel triangle inequality.  Equality at
the top of the **average conjugated operator** forces simultaneous equality
for every product conjugate; the spectral gap then upgrades this exact
kernel fact to a quantitative joint bound.

## 2. The PC.3 twirl has a depth-independent gap

Let `H_0` be the order-16 regular Hadamard child and let

```math
T_0={H_0\over4}.
```

Let `a,b,c` be the product-closed PC.3 triple and put

```math
Z_0=\{a,b,c,a\odot b\odot c\}.                   \tag{DS.9}
```

Define its conjugation twirl

```math
K_0={1\over4}\sum_{z\in Z_0}M_zT_0M_z.          \tag{DS.10}
```

Direct multiplication of the displayed finite seed gives the exact
identity

```math
\boxed{K_0^3=K_0,}
\qquad
\operatorname {mult}_{K_0}(1,0,-1)=(3,10,3).     \tag{DS.11}
```

This is a finite integer certificate: if

```math
L=\sum_{z\in Z_0}M_zH_0M_z,
```

then (DS.11) is exactly `L^3=16^2L`.

At tensor depth `j`, put

```math
T_j=T_0^{\otimes j},
\qquad
Z_j=Z_0^{\boxtimes j}
 =\{z_1\otimes\cdots\otimes z_j:z_t\in Z_0\}.   \tag{DS.12}
```

This is precisely the set of `4^j` active odd products generated by the
`p_j=2j+1` PC.3 ports.  Explicitly, projectivize by the base
`a^(tensor j)`.  The remaining `2j` local generators are independently
`ab` and `ac` in each factor; odd parity uniquely chooses whether the base
port is present, and the resulting local pole set is
`a*{1,ab,ac,(ab)(ac)}={a,b,c,abc}`.  Conjugation and averaging factor, so

```math
K_j={1\over|Z_j|}\sum_{z\in Z_j}M_zT_jM_z
   =K_0^{\otimes j}.                              \tag{DS.13}
```

By (DS.11), `spec(K_j) subseteq {-1,0,1}`.  Hence (DS.2) holds with the
same gap

```math
\boxed{\gamma=1}                                  \tag{DS.14}
```

at every depth.  This is the crucial point: the tensor tower does not erode
the twirl gap.

## 3. Uniform diagonal-switching coherence

Let `H_j=4^jT_j`, `n_j=16^j`, and `r_j=4^j=sqrt(n_j)`.  For any Boolean
diagonal switching `s in {+-1}^{n_j}`, set

```math
H_j^{(s)}=M_sH_jM_s.                              \tag{DS.15}
```

For an active product pole `z in Z_j`, define its switched positive-Rayleigh
deficit by

```math
d_z(s)=1-{z^TH_j^{(s)}z\over r_jn_j}
      =1-{s^TM_zT_jM_zs\over n_j}.               \tag{DS.16}
```

For an endpoint `epsilon in {+-1}^{p_j}`, let

```math
x_\epsilon(k)=\operatorname {Maj}
 (\epsilon_1w_1(k),\ldots,\epsilon_{p_j}w_{p_j}(k))             \tag{DS.17}
```

and define `d_epsilon(s)` by replacing `z` with `x_epsilon` in
(DS.16).

### Theorem DS.2 (PC.3 diagonal-switching rigidity)

At every tensor depth `j>=1`, every diagonal switching `s`, and every
endpoint `epsilon`,

```math
\boxed{
d_\epsilon(s)
\le {2\over4^j}\sum_{z\in Z_j}d_z(s)
\le2\max_{z\in Z_j}d_z(s).}                      \tag{DS.18}
```

In particular, for any sequence of switchings `s_j`,

```math
\max_{z\in Z_j}d_z(s_j)=o(1)
\quad\Longrightarrow\quad
\max_\epsilon d_\epsilon(s_j)=o(1).             \tag{DS.19}
```

Thus the sought vanishing-marginal/constant-selector separation is
impossible throughout this scalable exact-sign perturbation class.

#### Proof

The Boolean Fourier expansion of the odd majority selector gives

```math
x_\epsilon
=\sum_{S\text{ odd}}\widehat{\operatorname {Maj}}(S)
 \left(\prod_{i\in S}\epsilon_i\right)z_S.       \tag{DS.20}
```

Full odd-product closure identifies every `z_S` with an element of `Z_j`.
Hence the Boolean vector `x_epsilon` lies in `span(Z_j)`.  Apply Lemma DS.1
to `T_j`, `Z_j`, `x_epsilon`, and the gap (DS.14), then use (DS.16).
This proves (DS.18), uniformly in `epsilon`, and (DS.19) follows. `square`

Deleting the diagonal of `H_j^(s)` still gives a hollow exact signing.
The Boolean quadratic energies in (DS.16)--(DS.18) all change by the same
trace constant; since `tr(H_j)=0`, that constant is zero.  The no-go
therefore applies equally to the corresponding hollow signing at the
inherited Boolean energy scale.  If a genuine PSD contraction normalization
is wanted, use `r'_j=sqrt(n_j)+1`, since hollowing changes operator norm by at
most one.  Writing `c_j=sqrt(n_j)/(sqrt(n_j)+1)`, every new deficit is
`d'=(1-c_j)+c_jd`; hence (DS.18) implies

```math
d'_epsilon(s)\le2|Z_j|^{-1}\sum_zd'_z(s),        \tag{DS.20a}
```

and the vanishing implication is unchanged.

## 4. What this decides, and what remains open

Theorem DS.2 replaces a potentially large local-search campaign at orders
`256,4096,...` by an all-depth operator inequality.  It explains the finite
observation structurally:

* at order `256` (`p=5`), every selector defect is at most twice the mean of
  the 16 active-product deficits;
* at order `4096` (`p=7`), the same constant controls all 64 products and
  all 64 projective selector witnesses;
* the constant never grows with tensor depth.

The theorem does **not** say that exact signs always enforce coherence.
The five-port exact-sign construction in the separate note is not a
diagonal switching of the PC.3 tensor child with its canonical growing
ports, and it has fixed marginal deficit.  The remaining sharp question is
whether some genuinely non-switching exact-sign family can satisfy

```math
\max_S d_S=o(1),
\qquad
\max_\epsilon d_\epsilon\ge c>0,                 \tag{DS.21}
```

or whether an analogue of the gapped-twirl lemma is forced more broadly by
sign integrality and regular-Hadamard structure.

There is a precise way in which a non-switching construction could escape.
The following proposition reduces it to a diffuseness question rather than
leaving "arbitrary exact signs" completely unstructured.

### Proposition DS.3 (conditional sparse-flip escape)

Let `N` run through square orders, let `r=sqrt(N)`, and suppose `H` is a
symmetric entrywise-sign matrix with

```math
H^2=NI,
\qquad \operatorname {tr}H=0.                    \tag{DS.22}
```

Let `Z` be a family of Boolean positive `r`-eigenvectors and let the
Boolean positive `r`-eigenvector `x` satisfy

```math
\alpha_N=\max_{z\in Z}{|x^Tz|\over N}=o(1),
\qquad \log|Z|=o(N^{3/2}).                        \tag{DS.23}
```

For every fixed `0<kappa<1`, there exists a symmetric entrywise-sign matrix
`H'` with the same diagonal as `H` such that, writing `r'=||H'||_op`,

```math
{r'\over r}=1+o(1),                              \tag{DS.24}
```

and uniformly over `z in Z`,

```math
{z^TH'z\over r'N}=1-O(\alpha_N^2)-o(1),          \tag{DS.25}
```

whereas

```math
{x^TH'x\over r'N}=1-\kappa+o(1).                 \tag{DS.26}
```

Thus a diffuse selector would produce the exact-sign
vanishing-marginal/constant-coherent separation that diagonal switchings
cannot.

#### Proof

For every unordered off-diagonal pair with

```math
H_{ij}x_ix_j=1,                                  \tag{DS.27}
```

independently flip the two symmetric entries of `H` with probability

```math
q={\kappa\over\sqrt N}.                          \tag{DS.28}
```

Call the resulting signing `H'`.  For any Boolean `y`, its energy loss is

```math
y^T(H-H')y
=4\sum_{\{i,j\}\text{ flipped}}H_{ij}y_iy_j.    \tag{DS.29}
```

For a top pole `z`, the expectation of (DS.29) is

```math
q\left(rN+(x^Tz)^2-N\right).                     \tag{DS.30}
```

Indeed, insert
`1_(H_ij x_i x_j=1)=(1+H_ijx_ix_j)/2`, sum over
`i<j`, and use `z^THz=rN` and `tr(H)=0`.  After division by
`rN=N^(3/2)`, (DS.30) is

```math
\kappa\left({x^Tz\over N}\right)^2+o(1).         \tag{DS.31}
```

For `y=x`, every summand in (DS.29) is one.  The number of eligible edges
is

```math
{N(N-1)+rN\over4},                               \tag{DS.32}
```

so its normalized expected loss is `kappa+o(1)`.

Scalar Bernstein bounds make (DS.31) uniform over `Z` under the second
hypothesis in (DS.23), and give (DS.26), with probability tending to one.
For completeness, the centered matrix fluctuation has independent
symmetric edge summands bounded by two and matrix-variance parameter
`O(qN)=O(sqrt N)`.  Matrix Bernstein therefore gives

```math
\|H'-\mathbb EH'\|_{op}
=O(N^{1/4}\sqrt{\log N}+\log N)=o(\sqrt N)        \tag{DS.33}
```

with high probability.  Up to a diagonal matrix of norm at most `2q`,

```math
\mathbb EH'=(1-q)H-qxx^T.                        \tag{DS.34}
```

Since `Hx=rx`, the two terms in (DS.34) commute.  For `kappa<1`, its
operator norm is at most `r+o(r)`.  Thus `r'<=r+o(r)`.  Conversely every
full `N times N` sign matrix has Frobenius norm `N`, so `r'>=sqrt N=r`.
This proves (DS.24), and the energy estimates give (DS.25)--(DS.26).
`square`

For PC.3, the unresolved input to Proposition DS.3 is now explicit: find
endpoints whose selector witnesses obey

```math
\max_{z\in Z_j}{|x_\epsilon^Tz|\over n_j}=o(1).  \tag{DS.35}
```

A finite product-law computation for the periodic endpoint

```math
\epsilon_0=1,
\qquad \epsilon_{2t+1}=(-1)^t,
\qquad \epsilon_{2t+2}=(-1)^{\lfloor t/2\rfloor} \quad(0\le t<j) \tag{DS.36}
```

(where the last two coordinates index the two local relative generators)
gives the following maximum correlations for depths `j=2,...,10`:

```text
0.7500, 0.65625, 0.55469, 0.58594, 0.43311,
0.43811, 0.38107, 0.41563, 0.33625.
```

The maximizing product is a one-factor character throughout this range,
and the values are consistent with `Theta(j^(-1/2))`.  This is finite
evidence, not an asymptotic theorem.  Proving or falsifying (DS.35) for the
explicit three-atom PC.3 factor law is the exact next discriminator for
non-switching sparse flips.
