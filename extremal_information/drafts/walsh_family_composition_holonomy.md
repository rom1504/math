# Walsh-family composition: an exact carrier and an extensive holonomy obstruction

Status: rigorous task-local theorem and scalable counterexample, with an exact
finite verifier.  The result concerns compositions of the cap-`1/2` family in
[`bounded_cap_hadamard_response_packing.md`](bounded_cap_hadamard_response_packing.md).
It is **not** a result about the original unrestricted signing problem.

## 1. Setup

Put `q=2^m` and `n=q^2`.  Let `R` be the order-`q` Sylvester Walsh matrix

```math
R_{a,u}=(-1)^{a\cdot u},
\qquad R^2=qI,
```

and write `W=R\otimes R`.  A Boolean truth table
`g:F_2^m -> F_2` has sign diagonal

```math
D_g=\operatorname{diag}((-1)^{g(v)}:v\in F_2^m).
```

After the regularization and switching in the bounded-cap construction, the
quadratic landscape is exactly

```math
H_g(x)=\frac12 x^T C_gx,
\qquad C_g=R\otimes(D_gRD_g).                              \tag{WC.1}
```

Here and below `C_g` may retain its diagonal.  Its diagonal contribution on
the Boolean cube is the constant `tr(C_g)/2=0`, so (WC.1) is exactly the
hollow-child energy.  Every child obeys

```math
\max_x|H_g(x)|=\frac12n^{3/2}.                            \tag{WC.2}
```

Join adjacent blocks by the common Walsh bridge `W`.  For a graph `G` on
`[k]` and labels `g_1,...,g_k`, the composite energy is

```math
E_{G,\mathbf g}(x_1,\ldots,x_k)
=\frac12\sum_i x_i^TC_{g_i}x_i
 +\sum_{ij\in E(G)}x_i^TWx_j.                            \tag{WC.3}
```

## 2. Exact multi-block carrier

Define the `kq by kq` block matrix

```math
(K_{G,\mathbf g})_{ii}=D_{g_i}RD_{g_i},
\qquad
(K_{G,\mathbf g})_{ij}=
\begin{cases}
R,&ij\in E(G),\\
0,&ij\notin E(G).
\end{cases}                                               \tag{WC.4}
```

### Proposition WC.1 (Kronecker gauge carrier)

After reordering the coordinates from `(i,u,v)` to `(u,i,v)`, the full
matrix in (WC.3), before its harmless diagonal deletion, is exactly

```math
R\otimes K_{G,\mathbf g}.                                 \tag{WC.5}
```

Consequently graph gluing is exact block gluing of the carriers in (WC.4).
The carrier is generated by the graph and the `kq` truth-table bits, rather
than the `Theta(k^2q^4)` coefficients of a general `kn`-variable quadratic
landscape.

This is a genuine algebraic closure statement, but it is deliberately **not**
called an extremal-response quotient.  Evaluating the Boolean maximum of
`R\otimes K` still ranges over all `kq^2` spins.  Thus (WC.5) identifies an
explicit reduced place where a positive theorem could act; it does not hide
the original maximization inside the word "carrier."

There is a second useful gauge form.  Put `F=W/q`, let
`\tau_i(u,v)=(-1)^{g_i(v)}`, and set `z_i=D_{\tau_i}x_i`.  Then

```math
q^{-1}E_{G,\mathbf g}
=\frac12\sum_i z_i^TFz_i
 +\sum_{ij\in E(G)}z_i^T(D_{\tau_i}FD_{\tau_j})z_j.       \tag{WC.6}
```

The normalized edge transports

```math
U_{ij}=D_{\tau_i}FD_{\tau_j}                              \tag{WC.7}
```

are orthogonal and flat along paths:

```math
U_{i_0i_1}\cdots U_{i_{\ell-1}i_\ell}
=
\begin{cases}
D_{\tau_{i_0}}D_{\tau_{i_\ell}},&\ell\text{ even},\\
D_{\tau_{i_0}}FD_{\tau_{i_\ell}},&\ell\text{ odd}.
\end{cases}                                               \tag{WC.8}
```

Thus there is no label holonomy in the linear edge connection itself.  The
obstruction below is the relative holonomy between that connection and the
on-site Boolean quadratic.

## 3. A composition-created commutation bit

For `a in F_2^m`, take the linear truth table

```math
g_a(v)=a\cdot v,
```

let `M_a=diag((-1)^(a dot v):v in F_2^m)` and let
`D_a=I_q tensor M_a` be its diagonal lifted to the order-`n` Walsh space.
Set

```math
\widehat C_a=C_{g_a}/q=D_aFD_a.                           \tag{WC.9}
```

Both `F` and `\widehat C_a` are symmetric orthogonal involutions.  Walsh
modulation/translation gives

```math
F\widehat C_a=(-1)^{a\cdot a}\widehat C_aF.              \tag{WC.10}
```

The bit `a\cdot a` is invisible to the bias and pairwise truth-table
overlaps used by the one-bridge low-bias certificate, but it controls whether
the bridge carries a child maximizing eigenspace into itself or into its
negative.

For a graph `G` on `k` blocks put

```math
\mathcal M_a=I_k\otimes\widehat C_a
             +A(G)\otimes F.                             \tag{WC.11}
```

Then (WC.3) for the constant word `(g_a,...,g_a)` is

```math
E_{G,a}(X)=\frac q2X^T\mathcal M_aX.                     \tag{WC.12}
```

### Theorem WC.2 (bipartite Walsh-holonomy separation)

Suppose `m>=2`.  Choose nonzero `a_0,a_1 in F_2^m` with

```math
a_0\cdot a_0=0,
\qquad a_1\cdot a_1=1.                                  \tag{WC.13}
```

Both truth tables are balanced.  In either constant word, every off-diagonal
pairwise truth-table correlation is `q`, and every correlation with the
constant table is zero.  In other words, the retained lists
`(S(g_i,0),S(g_i,g_j))` are identical for the two words; no assertion is
being made about the cross-correlation `S(g_{a_0},g_{a_1})`.  If `G` is
bipartite, nevertheless

```math
\max_XE_{G,a_0}(X)
=\left(\frac{k}{2}+|E(G)|\right)n^{3/2},                 \tag{WC.14}
```

whereas

```math
\max_XE_{G,a_1}(X)
\le
\frac k2\sqrt{1+\|A(G)\|_{2\to2}^2}\;n^{3/2}.          \tag{WC.15}
```

For the path `G=P_k`, pairwise truth-table overlaps, even augmented by all
individual biases, therefore miss at least

```math
\Delta_k n^{3/2},
\qquad
\Delta_k=\frac{3k}{2}-1
-\frac k2\sqrt{1+4\cos^2\!\frac{\pi}{k+1}}>0.          \tag{WC.16}
```

For a long path the missing amount is extensive:

```math
\frac{\Delta_k}{k}\longrightarrow
\frac{3-\sqrt5}{2}=0.381966\ldots.                       \tag{WC.17}
```

#### Proof

For even `a_0\cdot a_0`, (WC.10) says that `F` and
`\widehat C_{a_0}` commute.  The usual child pole `s_{g_{a_0}}` is a Boolean
`+1` eigenvector of `\widehat C_{a_0}`.  Its Walsh dual
`Fs_{g_{a_0}}` is also Boolean and, by commutation, is another `+1`
eigenvector.  Assign these two vectors according to the two color classes of
`G`.  This simultaneously saturates every child term at `nq/2` and every
bridge at `nq`.  The separate operator-norm bounds on the terms give the
matching upper bound, proving (WC.14).

For odd `a_1\cdot a_1`, the two involutions anticommute.  Squaring (WC.11)
cancels the cross term:

```math
\mathcal M_{a_1}^2
=(I_k+A(G)^2)\otimes I_n.                                 \tag{WC.18}
```

Hence

```math
||\mathcal M_{a_1}||
=\sqrt{1+\|A(G)\|_{2\to2}^2}.                           \tag{WC.19}
```

Every Boolean block vector has squared Euclidean norm `kn`; the Rayleigh
bound in (WC.12) proves (WC.15).  On a path,
`||A(P_k)||=2cos(pi/(k+1))`; positivity of `\Delta_k` follows directly for
`k>=2`: at `k=2` the two coefficients are `2` and `sqrt(2)`, while for
`k>=3` one has `(3-2/k)^2>=49/9>5` and
`1+4cos^2(pi/(k+1))<5`.

## 4. What this settles and what remains open

The theorem gives a scalable, target-scale rejection of a natural proposed
quotient:

```math
\boxed{\text{biases + pairwise truth-table overlaps are not reusable under
Walsh-bridge composition.}}
```

The one-bridge low-bias proof sees the scalar Rayleigh coordinate
`S(g,h)^2/q^2`.  Repeated interaction exposes an additional commutation
cocycle.  It is a concrete instance of composition-created information:
the edge connection (WC.8) is flat, yet its compatibility with the on-site
quadratic has a nontrivial `Z/2` phase and produces extensive energy drift.

The result does **not** prove that the full `q`-bit truth table is
non-reusable.  Proposition WC.1 shows exact coefficient-level closure through
`kq` label bits, but no theorem here computes arbitrary future extrema from a
depth-independent `O(q)` response state.  Establishing such a quotient, or
proving `Omega(kq)` terminal contextual information for suitable chains,
remains open.  In particular, the theorem must not be advertised as an
incompressibility result for the whole cap-`1/2` class.
