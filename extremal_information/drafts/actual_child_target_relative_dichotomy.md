# Target-relative basin/dependence dichotomy for the actual child escort

Status: **task-local rigorous theorem note**.  This note combines the exact
row-product shadow identity in
[`actual_child_negative_escort_structure.md`](actual_child_negative_escort_structure.md)
with a one-sided moment argument.  It gives an exhaustive structural
dichotomy *conditional on the actual soft bridge reaching a declared target*:
either a bounded-row-Renyi product law already exposes a linearly rare basin,
or the directed reverse projection onto row products is extensive.  No
conference or Paley child appears.

The theorem does not prove that the soft bridge reaches the target, and it
does not decide which branch occurs asymptotically.

## 1. Setup

Fix a split `m+n=N`, raw temperature

```math
t={\beta\over\sqrt N},
```

contracted-temperature minimizing children `A,D`, and one relative
orientation `epsilon`.  On the fair bridge cube `U_B`, put

```math
L(B)=\log \overline Z_N(A,\epsilon D,B;t),
\qquad
V_\lambda=-{1\over\lambda}\log\mathbb E_{U_B}e^{-\lambda L(B)}.
                                                               \tag{TR.1}
```

Let `P_row` be the independent-row laws and set

```math
V_\lambda^{\rm row}
=\min_{p\in\mathcal P_{\rm row}}
 \left\{\mathbb E_pL+{1\over\lambda}D(p\Vert U_B)\right\},
\qquad
\mathcal I_\lambda^{\leftarrow}
=\inf_{p\in\mathcal P_{\rm row}}D(p\Vert q_\lambda).
                                                               \tag{TR.2}
```

Here `q_lambda proportional e^(-lambda L)U_B`.  The exact Gibbs identity is

```math
\mathcal I_\lambda^{\leftarrow}
=\lambda(V_\lambda^{\rm row}-V_\lambda).             \tag{TR.3}
```

Let `T` be any declared target pressure and define

```math
L_0=L(0),\qquad h=T-L_0,\qquad
\Delta=V_\lambda^{\rm row}-T.                        \tag{TR.4}
```

For the composition problem, `T` is normally the sum of the two
same-temperature child pressures.  The theorem below is pointwise and does
not need that specialization.

## 2. A sectorwise pressure floor

**Lemma TR.1 (zero-bridge floor).**  For every bridge `B`,

```math
\boxed{L(B)\ge L(0).}                                 \tag{TR.5}
```

*Proof.*  Relative to the parent law at zero bridge, the partition-function
ratio is

```math
{\overline Z_N(A,\epsilon D,B;t)
 \over\overline Z_N(A,\epsilon D,0;t)}
=\mathbb E_{\mu_{0,\epsilon}}
  e^{t\langle B,Q\rangle},                           \tag{TR.6}
```

where `Q=tau xy^T`.  Sending all left spins `x` to `-x` preserves the
zero-bridge weight and sends `Q` to `-Q`.  Hence the right side is
`E cosh(t<B,Q>)>=1`. `square`

In particular, if `V_lambda<=T`, then necessarily `h>=0`.  In the signing
application `0<=L_0` and the annealed bound gives `T=O_beta(N)`, so
`0<=h=O_beta(N)` whenever the target is reached.

## 3. The exact target-relative dichotomy

**Theorem TR.2 (product basin or directed extensive dependence).**  Let
`p^*=tensor_(i=1)^m p_i^*` be any minimizer in (TR.2).  Then every row obeys

```math
D_2(p_i^*\Vert U_n)
\le n\log(1+\tanh^2(\lambda t))
\le\lambda^2t^2n,                                    \tag{TR.7}
```

and consequently

```math
D_2(p^*\Vert U_B)
=\sum_iD_2(p_i^*\Vert U_n)
\le {\lambda^2\beta^2mn\over N}.                    \tag{TR.8}
```

For every `a>Delta` with `h+a>0`, define

```math
G_a=\{B:L(B)\le T+a\}.
```

Then

```math
\boxed{
p^*(G_a)\ge {a-\Delta\over h+a},
\qquad
U_B(G_a)\ge
 \exp\!\left(-{\lambda^2\beta^2mn\over N}\right)
 \left({a-\Delta\over h+a}\right)^2.}               \tag{TR.9}
```

On the other hand, for every error `e` such that `V_lambda<=T+e`,

```math
\boxed{
\mathcal I_\lambda^{\leftarrow}
\ge\lambda(\Delta-e).}                               \tag{TR.10}
```

Thus, along comparable splits at fixed `beta,lambda`, if

```math
V_\lambda\le T+o(N),                                 \tag{TR.11}
```

there are only two asymptotic possibilities:

1. `Delta_+=o(N)`.  Since `V_lambda>=L_0`, (TR.11) also implies
   `(-h_N)_+=o(N)`.  For example, choosing
   `a_N=2(Delta_N)_++2(-h_N)_++sqrt(N)` gives `a_N=o(N)`,
   `h_N+a_N>0`, and
   `(a_N-Delta_N)/(h_N+a_N)>=N^(-1/2)/C_beta` whenever
   `h_N=O_beta(N)`.  Hence

   ```math
   L(B)\le T+o(N)
   ```

   on a bridge set of uniform probability `exp[-O_(beta,lambda)(N)]`.
   This basin is generated by an independent-row law whose component
   Renyi-two complexities are uniformly bounded.  If more quantitatively
   `Delta_+=O(N^(1-delta))`, the pressure defect can be chosen
   `O(N^(1-delta))`, which is the Hammersley-summable scale used by the
   existing basin-to-convergence criterion.  A bare `o(N)` defect alone is
   not claimed sufficient for convergence.  The quantitative conclusion
   also requires `(-h_N)_+=O(N^(1-delta))`; this is automatic under exact
   target reachability `V_lambda<=T`, because then `h_N>=0`.

2. Along some subsequence `Delta>=eta N` for a fixed `eta>0`.  Then

   ```math
   \mathcal I_\lambda^{\leftarrow}
   \ge(\lambda\eta-o(1))N,                            \tag{TR.12}
   ```

   so the actual escort has irreducible extensive dependence in the exact
   directed variational sense relevant to its pressure.

*Proof.*  The row bound (TR.7) is Theorem AC.3: every coordinate best
response has one-bit log oscillation at most `2lambda t`.  Renyi divergence
is additive for products, proving (TR.8).

Since the entropy term is nonnegative,

```math
\mathbb E_{p^*}L\le V_\lambda^{\rm row}=T+\Delta.
```

Apply Markov's inequality to the nonnegative variable `L-L_0` from Lemma
TR.1:

```math
p^*\{L>T+a\}
\le {\mathbb E_{p^*}(L-L_0)\over T+a-L_0}
\le {h+\Delta\over h+a}.                             \tag{TR.13}
```

This proves the first part of (TR.9).  If `f=dp^*/dU_B`, Cauchy--Schwarz
gives

```math
p^*(G_a)^2
\le U_B(G_a)\mathbb E_{U_B}f^2
=U_B(G_a)e^{D_2(p^*\Vert U_B)},                       \tag{TR.14}
```

and (TR.8) proves the second part.  Finally, (TR.3) gives

```math
\mathcal I_\lambda^{\leftarrow}
=\lambda(V_\lambda^{\rm row}-V_\lambda)
\ge\lambda(T+\Delta-T-e),                            \tag{TR.15}
```

which is (TR.10).  The asymptotic alternatives follow immediately.
`square`

## 4. What this adds to the structural campaign

The dichotomy uses the actual optimized-child pressure and the exact
negative escort.  It is stronger than classifying KL or total correlation:

- large forward row total correlation does not force branch 2;
- branch 2 uses the reverse projection which is exactly the missing
  variational pressure;
- branch 1 is not merely a small information number: it constructs a
  linearly rare, `o(N)`-accurate target basin with explicit mass.

The finite target-reaching example at `N=8`, split `4+4`, `beta=4`, and
`lambda approximately 5.382104` illustrates why the direction matters.  Its
forward row total correlation is about `.585N`, while the best evaluated
row-product law captures about `76.4%` of the escort gain.  This is numerical
evidence only, but it decisively warns against replacing (TR.10) by total
correlation.

Equation (TR.9) also explains the correct positive use of a product shadow.
If its target excess has a power saving, it supplies exactly the linearly
rare basin required by the existing entropy-tilted composition criterion.
A general sublinear excess still supplies an `o(N)`-accurate basin, but the
project's almost-subadditivity audit correctly warns that an unspecified
`o(N)` defect need not force convergence.  If the excess is linear while the
full soft bridge reaches the target, then (TR.10) certifies a genuinely
extensive interaction resource.

## 5. New smallest missing lemma

The previous SML asked vaguely which term of the uniform-to-escort gain was
linear.  The target-relative theorem reduces that question to one scalar:

> **Actual-child row-product target-excess lemma.**  For contracted-
> temperature minimizing children and a fixed target-reaching
> `beta,lambda`, determine whether
> `Delta_N=V_lambda^row-T_N` has positive part `o(N)`, or is bounded below by
> `eta N` along a subsequence.  The proof must control `Delta_N` from a
> nonradial statistic of the children strictly smaller than the full bridge
> response table.

The last information clause is essential.  The coordinate best-response
oracle for `V_lambda^row` can reconstruct the complete table of `L` when
queried on point masses.  Merely renaming the nonconvex row-product
optimization is not a strict reduction.

This SML is narrower than “understand the actual child-induced law”: tight
conditional row complexity, the exact positive basin branch, and the exact
extensive-dependence branch are all proved.  It is not yet a Level-5-to-6
route because no low-information child statistic decides the sign of
`Delta_N`.
