## 1. Scope and mandatory thickening

Write

```math
H_A(x)=\sum_{i<j}a_{ij}x_ix_j,
\qquad Q(A)=\max_x|H_A(x)|,
\qquad s_n=n^{3/2}.
```

For two signings let `e(A,B)` be their number of differing unordered edges
and put

```math
d_\square(A,B)=\max_x|H_A(x)-H_B(x)|.
```

Then

```math
d_\square(A,B)\le 2e(A,B),                         \tag{1.1}
```

and every shared max-type future changes by at most `d_square(A,B)`.  This
is the only safe way to state a near-minimizer property in the presence of
the `o(n^(3/2))` edit halo.  If a property `P` is imposed on a core `B`, its
thick version will mean

```math
P^[h](A):\quad \text{there is a core }B\text{ with }
d_\square(A,B)\le h\text{ and }P(B).               \tag{1.2}
```

Changing a further `r` edges only replaces `h` by `h+2r`.  In a candidate
near-minimality lemma the correct scale is

```math
h\le [f(\epsilon)+o_n(1)]s_n,
\qquad f(\epsilon)\longrightarrow0.                \tag{1.3}
```

This absorbs both geodesic radial motion and localized spectral implants; it
does not absorb the fixed-density-at-`s_n` sparse-flip collision as
`epsilon -> 0`.

All response properties below are interface-relative.  A port family or
finite carrier must contain every interface actually generated by the
declared composition tree; choosing an empty family is not allowed.  This is
the nonvacuity condition inherited from response duality.

The campaign phrase "less information than `Q`" cannot literally mean fewer
data than the single scalar `Q(A)`.  The operational requirement used below,
consistent with `PROGRESS_FRONTIER.md`, is that `P` neither determines
`Q(A)` nor retains the full Boolean response landscape.  Each candidate has
an explicit subextensive carrier or a strict structured replacement.

## 2. Candidate P1: edit-thick collective selector coercivity

### 2.1 Exact property

Let `B` be a hollow exact signing (a rational weighted core would give the
same implication), and let

```math
\|B\|_(2\to2)\le r,
\qquad r=\Theta(\sqrt n),                          \tag{2.1}
```

and let `W=(w_1,...,w_p) in {+-1}^{n times p}` be a declared Boolean port
frame.  Fix an antipodally odd selector `tau`.  List as columns of `Z` all
products

```math
z_S=\bigodot_(i\in S)w_i
```

in the nonzero Boolean Fourier support of `tau`, and define

```math
G={Z^TZ\over n},\qquad
R={Z^TBZ\over rn},\qquad
D=G-R\succeq0.                                    \tag{2.2}
```

For endpoint `epsilon`, put

```math
a_S^epsilon=\widehat\tau(S)\prod_(i\in S)epsilon_i,
\qquad
\Delta_tau(B,W)=\max_epsilon
 (a^epsilon)^TD a^epsilon.                        \tag{2.3}
```

This is the joint selector defect, not the list of marginal defects
`D_SS`.  For a declared family `mathscr W` define its coercivity modulus

```math
\mathfrak C_tau(B;mathscr W)
=\sup_(W\in mathscr W)\Delta_tau(B,W).             \tag{2.4}
```

The family is required to contain every logarithmic-port frame produced by
the intended composition.  A useful optional strengthening, closer to a
candidate theorem about `B` alone, is

```math
\sup\left\{\Delta_tau(B,W):
 p\le p_n,\ \max_S D_SS\le d_n\right\}\le\beta_n. \tag{2.5}
```

Property `P1(h,beta,p_n)` says that `A` has a core `B` satisfying (2.1),

```math
d_\square(A,B)\le h,
\qquad p\le p_n,
\qquad \mathfrak C_tau(B;mathscr W)\le\beta,       \tag{2.6}
```

and every realized port shore has width `m` with

```math
c={mp\over r}=O(1),\qquad mp=o(n).                 \tag{2.7}
```

The allowed physical alternative is a balanced compiler of the form proved
in Theorem 21.66: every free endpoint field is `l_1`-close, at `o(s_n)`
cost, to a scalar multiple `aW epsilon` with `|a|<=1`, and the effective
field mass in (2.7) is bounded.  This alternative matters when the raw shore
has `mp/r -> infinity` but endpoint balance keeps every realized field at
the target scale.

For tensor reuse, the presentation also carries the additive certificate
budget `sum_v beta_v` along a root--leaf factorization.  A Doeblin mass for
the histogram convolution may be added when depth-uniform forgetting rather
than additive error is required.

### 2.2 Closed sufficiency implication

Let `mu_W` be the projective row histogram, and let `tilde mu` approximate it
to `d_p`-error at most `eta`.  Theorems 21.50 and 21.54 give a decoder whose
uniform labelled trust-response error is

```math
E_n\le
h+rn\left({\beta\over2}+c\eta\right)
+O((mp)^2).                                        \tag{2.8}
```

Indeed, Theorem 21.54 pays the joint quadratic loss by `rn beta/2`, while

```math
m\|W\epsilon\|_1=rn\,c\,R_(mu_W)(\epsilon)
```

pays `rn c eta` for histogram replacement.  Equation (1.1) pays `h` for
returning from the core to `A`.  A common exact-sign completion on the new
shore costs `O((mp)^2)`.

At fixed `eta`, the response code uses

```math
O(p/eta^2)\quad\text{bits}.                        \tag{2.9}
```

Thus

```math
h=o(s_n),\quad beta=o(1),\quad eta=o(1),
\quad p/eta^2=o(n),\quad mp=O(\sqrt n)             \tag{2.10}
```

give both `E_n=o(s_n)` and a sublinear response state.  For example,
`p=O(log n)` and `eta=1/log n` use `O(log^3 n)` bits.

The dynamic part is already proved rather than conjectural.  Under
corresponding-port products, Theorem 21.54 gives

```math
\Delta_(tau,1\otimes\cdots\otimes L)
\le\sum_(i=1)^L\Delta_(tau,i).                    \tag{2.11}
```

The histogram itself composes by exact projective-group convolution.
Theorem 21.53 gives either independent-occurrence, depth-independent
sampling or the contraction law

```math
e_L\le e_0\prod_j(1-alpha_j)
 +\sum_i eta_i\prod_(j>i)(1-alpha_j)              \tag{2.12}
```

when successive histogram kernels contain uniform masses `alpha_j`.
Therefore the only extra composition datum is the scalar defect budget;
the entire Boolean roof is not being smuggled into the state.

### 2.3 Why the known obstructions do not kill P1

* Equal port Gram--Rayleigh data are insufficient by Theorem 21.51.  P1
  evaluates the Fourier-product selector quadratic form (2.3), which is
  precisely the higher coherent channel absent from that collision.
* The sparse-flip children in Theorems 21.62--21.67 have all marginal active
  product deficits `o(1)` but one selector deficit `kappa+o(1)`.  They
  therefore **fail** (2.5) with `beta=o(1)` and are not falsely identified.
  Their physical compiler confirms that this is a response-relevant failure,
  not merely a spectral certificate artifact.
* An `o(s_n)` edge-edit halo is absorbed by `h`.  The fixed-`kappa`
  sparse-flip construction makes `Theta(s_n)` targeted edits and cannot be
  hidden in (1.3) as `epsilon -> 0`.
* A gapped conjugation twirl is a finite sufficient certificate for (2.5):
  Theorem 21.60 bounds every selector defect by `2/gamma` times the average
  conjugated pole deficit.  This is a possible proof route, not part of the
  definition.

P1 contains strictly less information than the full response landscape.
Its runtime state is (2.9) plus a scalar error budget.  Full Boolean pinning
recovers every landscape value by Proposition 4.6.  Moreover exact
synchronization can coexist with different cap phases (Theorem 21.57), so
the predicate `beta=0` does not determine `Q(A)`.

A finite falsifier is explicit: one frame `W` and endpoint `epsilon` for
which `(a^epsilon)^TD a^epsilon>beta`.  All quantities are finite quadratic
forms.  For the thick existential form, finite enumeration of candidate
edit cores decides the property; a proposed core is falsified either by a
spin witnessing `d_square(A,B)>h`, by `||B||>r`, or by the same selector
witness.

### 2.4 Exact SML candidate

Find `p_n=O(log n)`, a nonvacuous balanced cross-scale port language, and a
function `f(epsilon)->0` such that every
`A in mathcal N_n(epsilon)` has a core presentation with

```math
{h\over s_n}+\mathfrak C_tau(B;mathscr W)
\le f(epsilon)+o_n(1),                             \tag{2.13}
```

`r=Theta(sqrt n)`, `mp=O(sqrt n)`, and cumulative defect
`sum_v beta_v=o(1)` on the declared balanced composition tree.  Equation
(2.8), not a new composition conjecture, then gives the desired transfer.

## 3. Candidate P2: edit-thick contracting fibre with sparse recurrent memory

### 3.1 Exact property

Property P2 is deliberately semantic and allows the sparse-flip bit to be
stored rather than forcing it to disappear.  Normalize responses by `s_n`.
The declared finite response generators of a core `B` must admit a finite
directed carrier `G=(Q,E)` with fibre laws `pi_q` and every stochastic secant
`P_e` satisfying

```math
P_e1=1,\qquad pi_qP_e=pi_(q'),\qquad
\|P_eh\|_(2,pi_q)\le rho\|h\|_(2,pi_(q')),
\quad rho\le1-gamma                               \tag{3.1}
```

for one `gamma>0`.  Terminal and edge residuals split into mean and centred
parts as in Theorem 33.1.  Require:

1. normalized terminal and centred-edge dictionaries have cover costs

   ```math
   b_U=\log N_U(zeta),\qquad
   b_B=\log N_B(gamma zeta);                       \tag{3.2}
   ```

2. the recurrent scalar cochain quotient has rank

   ```math
   r_G=|E|-|Q|+1                                   \tag{3.3}
   ```

   (componentwise in the non-strongly-connected case), and its coordinates
   either are stored exactly with `O(log n)` bits each or are quantized at
   mesh `xi` for a declared maximum depth `D`;
3. the original signing is within `h` in `d_square` of this carrier core.

Scalar gradient potentials are not free: they must be public gauges or be
included in the terminal cover cost `b_U`.  This is the endpoint-gauge
qualification in Theorem 33.1.

The quantitative property is

```math
h=o(s_n),\qquad zeta=o(1),
\qquad b_U+b_B+r_G\log(1+L/xi)=o(n),               \tag{3.4}
```

with `D xi=o(1)` if cohomology is quantized.  With exact integral/rational
cohomology coordinates one can replace the last term by `O(r_G log n)` and
remove the depth loss.

### 3.2 Closed sufficiency implication

The expansion in Theorem 33.1 separates exactly three channels:

```math
\text{terminal centred mass }rho^tR,
\quad\text{fresh centred shell }B/(1-rho),
\quad\text{recurrent scalar cohomology}.           \tag{3.5}
```

Consequently P2 has a reusable code of

```math
b_U+b_B+O(r_G\log n)                               \tag{3.6}
```

bits when scalar classes are stored exactly, and all-depth response error

```math
E_n\le h+O(zeta s_n).                              \tag{3.7}
```

If the scalar class is quantized instead, add `O(D xi s_n)` to (3.7).
This is just Theorem 33.1 with no approximation in the scalar channel.
Theorem 33.2 extends the same implication to switching nonlinear max maps
provided all realized secants obey the common-law condition (3.1).

This property is not a recoding of the Boolean landscape.  It stores two
metric covers and `r_G` cycle coordinates; endpoint potentials and every
centred fibre detail below the forgetting scale are discarded.  The state
bound (3.6) is `o(n)` under (3.4), whereas full Boolean pinning is lossless.
The same carrier can support many different endpoint gauges and response
values, so P2 does not determine `Q(A)`.

### 3.3 Collision, edit, and falsifier audits

* The physical sparse-flip construction exposes one persistent bit.  A P2
  realization may store it in one terminal or recurrent coordinate, so that
  one-bit collision does not by itself kill the property.  A growing
  multi-selector packing would force growing terminal entropy, `r_G`, or
  fresh rebroadcast incidence and would test (3.4) quantitatively.
* Theorem 34.1 makes this diagnostic exact: centred hidden information is
  forgotten, while `h` persistent rate-separated bits obey
  `h epsilon<=J_A`.  Thus a large physical selector packing is a finite
  obstruction to a low-incidence P2 carrier, not an unmodelled fourth
  response channel.
* An `o(s_n)` edit halo is paid by `h`; alternatively its scalar projection
  is stored in cohomology and its centred projection is geometrically
  forgotten.  No operator-norm conclusion about the edited signing is used.

Finite falsifiers are built into the definition.  On a proposed finite
carrier one can exhibit (i) a secant with no common transported law,
(ii) a centred singular value exceeding `1-gamma`, (iii) a simple directed
cycle with forbidden mean circulation, or (iv) more independent cycle
classes/response-separated reward words than (3.4) allows.  All are finite
linear-algebra or finite-path certificates.

### 3.4 Exact SML candidate

Prove that every `A in mathcal N_n(epsilon)` has, after
`[f(epsilon)+o(1)]s_n` response residual, a common-law carrier with fixed
`gamma>0` and

```math
\log N_U(zeta_n)+\log N_B(gamma zeta_n)
  +O(r_G\log n)=o(n),\qquad zeta_n=o(1).           \tag{3.8}
```

Unlike P1, this SML need not make every coherent defect vanish.  It asks
that persistent defects occupy only a sparse recurrent quotient.

## 4. Candidate P3: edit-thick switched finite-type replacement

### 4.1 Exact property

Let `mathcal C_(n,q)` be the class of switched `q`-type exact signings.  A
member has a type map `t:[n]->[q]`, a switch `d in {+-1}^n`, and a symmetric
sign kernel `S in {+-1}^{q times q}` such that

```math
B_(ij)=d_id_jS_(t(i),t(j))\qquad(i\ne j).          \tag{4.1}
```

Property P3(h,q) says

```math
\text{there is }B\in mathcal C_(n,q)
\text{ with }d_\square(A,B)\le h,
\qquad q\log(n+1)=o(n).                           \tag{4.2}
```

The Hamming-strong version asks for
`e(A,B)<=h/2`, which implies (4.2) and is manifestly stable under further
edge edits.  The switch makes the class invariant under the switching
symmetry of `Q`.

### 4.2 Closed sufficiency implication

Put `y_i=d_ix_i`, let `n_a=|t^{-1}(a)|`, and retain the type magnetizations

```math
u_a=\sum_(i:t(i)=a)y_i.                            \tag{4.3}
```

Then the energy is exactly

```math
H_B(x)=\sum_(a<b)S_(ab)u_au_b
       +{1\over2}\sum_aS_(aa)(u_a^2-n_a).         \tag{4.4}
```

There are at most

```math
\prod_a(n_a+1)\le(n+1)^q                          \tag{4.5}
```

feature states, so a state label uses `q log_2(n+1)=o(n)` bits.  Under
disjoint merge, the vectors `u` add and every type-kernel cross energy is
bi-affine.  Theorems 4.3 and 4.4 therefore give an exact,
bracket-independent response algebra on `B`.

Equation (4.2) and max nonexpansiveness give, for every shared future,

```math
|R_A-R_B|\le h.                                    \tag{4.6}
```

For several leaves, Theorem 4.3 makes the losses add.  Hence

```math
h=[f(epsilon)+o_n(1)]s_n,
\qquad f(epsilon)\longrightarrow0                 \tag{4.7}
```

is an `o(s_n)` exact-sign response replacement as `epsilon -> 0`, with a
strictly subexponential feature carrier.  This proves the response and
composition part of Route R3.  A common/refinable type kernel across all
orders would still be needed for the final cross-size step.

P3 is not a disguised scalar cap condition.  It asserts an explicit
finite-type factorization and forgets all within-type edge labels.  Its
interface has (4.5) states rather than `2^n` spins, and arbitrary Boolean
pinning can distinguish matrices with the same `q` and error radius.  The
property therefore does not determine `Q(A)`; a supplied core only
approximates it to the declared `h`.

### 4.3 Collision, edit, and falsifier audits

* If the two physical sparse-flip parents of Theorem 21.67 were both
  `o(s_n)`-close to the same core, max nonexpansiveness would contradict
  their fixed response gap.  P3 therefore never identifies that collision;
  it must assign distinct cores or fail on at least one parent.
* Geodesic planting and a clique on `n^(2/3)` vertices change only
  `o(s_n)` edges and are absorbed by `h`.  P3 makes no unpeeled operator-norm
  assertion.
* For a proposed `(t,d,S)`, a spin with
  `|H_A(x)-H_B(x)|>h` is a finite response falsifier.  Exact membership has
  an even smaller witness: whenever `i,i'` share one proposed type and
  `j,j'` another,

  ```math
  B_(ij)B_(ij')B_(i'j)B_(i'j')=1.                 \tag{4.8}
  ```

  for four distinct vertices.  A negative rectangle falsifies that type
  assignment.  A finite packing
  of incompatible rectangles certifies a lower bound on `q` or on the edit
  budget.  Globally, the existential property is finite and decidable by
  enumerating type maps, switches, kernels, and Boolean response witnesses.

### 4.4 Exact SML candidate

Find `q_n` with `q_n log n=o(n)` and `f(epsilon)->0` such that every
`A in mathcal N_n(epsilon)` has a switched `q_n`-type exact signing `B`
satisfying

```math
d_\square(A,B)
\le[f(epsilon)+o_n(1)]n^{3/2}.                    \tag{4.9}
```

The Hamming version with the same right side is stronger and automatically
passes the edit-halo audit.  The archived weak-regularity ceiling concerns
arbitrary bounded-cap signings; (4.9) is useful only if near-minimality
forces the improvement.

## 5. Which sufficiency implication is strongest?

P1 has the sharpest already-closed implication.  It adds exactly the
coherent scalar missed by Gram/marginal states, and (2.8) gives both a
numerical `o(n^(3/2))` loss and `o(n)` reusable bits.  Tensor reuse and
forgetting are already theorems.  The missing work is genuinely
`near-minimality => P1` plus a nonvacuous interface presentation, not another
composition lemma.

P2 is the broadest semantic candidate.  It is the only one of the three that
can absorb a small number of physical hidden coherence bits as memory rather
than declaring them defects.  Its risk is assumption distance: discovering
a common transported law and strict secant contraction may be nearly as hard
as discovering the carrier itself.

P3 is the cleanest replacement target and the easiest to falsify.  It gives
exact-sign realization and exact bi-affine composition, but arbitrary-order
compatibility of the type kernels remains a separate step.  It should be a
backup Route-R3 SML, not a substitute for collective synchronization.

Recommended ranking for director comparison:

1. **P1, collective selector coercivity modulo an `eta`-thick residual.**
2. **P2, contracting fibre with sparse recurrent cohomology.**
3. **P3, switched finite-type response replacement.**

If only two candidates are promoted, P1 is mandatory.  Choose P2 when the
multi-selector collision remains low-rank; choose P3 if experiments show
finite-type/cut-response clustering on actual minimizers.

## 6. Post-freeze comparison with deterministic inequalities

The independent deterministic report changes none of the definitions, but
it imposes the following interpretation.

| candidate | deterministic contact | verdict |
|---|---|---|
| P1 | Set-dependent flip witnesses do not produce the common Fourier selector bound (2.3).  Thin-shell eutaxy is destroyed by geodesic planting. | Only the thick form (2.13) survives.  Marginal/first-moment versions must not be substituted. |
| P2 | The flip inequality has the wrong quantifier for a common law.  A geodesically planted face is naturally a radial memory coordinate. | Not falsified, but the common-law hypothesis is a genuine new lemma.  Exact scalar cohomology is preferable to a thin-shell balance claim. |
| P3 | Unpeeled `||A||=O(sqrt n)` is false by an `n^(2/3)` clique implant. | The switched, edit-thick response approximation survives because it peels the implant into `h`; no spectral bound on `A` is asserted. |

Three hard guardrails follow.

1. A universal property must be thick on the full optimality-excess scale,
   not merely on an `O(n)` near-cap shell.
2. Switching invariance must be built into either the property or its gauge.
3. Marginal balance, flat eigenvectors, and individual product quality are
   not acceptable proxies for a common collective carrier.

The deterministic report proves no arrow from near-minimality to P1--P3.
It does, however, explain why the residual terms in (2.13), (3.8), and (4.9)
are structural rather than cosmetic.
