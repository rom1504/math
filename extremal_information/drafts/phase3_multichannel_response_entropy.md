# Multichannel response entropy without channel queries

**Status.**  The statements below are proved.  The finite identities and
examples are checked by
[`verify_phase3_multichannel_response_entropy.py`](../experiments/verify_phase3_multichannel_response_entropy.py).

This note determines the correct object behind the multichannel kernel
profile

```math
F_V(u)=\min_{z\in\mathbb F_2^k}
       \left(2|z|+|u+Vz|\right),
\qquad u\in\mathbb F_2^D.                     \tag{MR.1}
```

Exactly, it is a weighted Cayley metric and remembers the set of all
nonredundant generators, not merely their span.  At macroscopic additive
distortion, the ordinary linear code spanned by the generators is a useful
coarse quotient when `k` is small relative to `D`.  Asymptotically good
linear codes then give a packing of these profiles with
`Omega(Dk)` bits, even though the queries have no channel label.  Thus the
`Dk` mixed-holonomy count in the composition exact sequence can be genuine
response information rather than merely gauge bookkeeping.

## 1. The exact effective object

Let `W=F_2^D`, let `V=(v_1,...,v_k)` be an indexed list in `W`, and regard
`V` also as the linear map `F_2^k to W` with these columns.  Give coordinate
generators of `W` cost one and each `v_j` cost two.

### Proposition MR.1 (weighted generator metric and exact collisions)

The function `F_V` is the translation-invariant weighted Cayley word norm
on `W` generated by

```math
\{e_1,\ldots,e_D\}\quad\text{at cost }1,
\qquad
\{v_1,\ldots,v_k\}\quad\text{at cost }2.       \tag{MR.2}
```

Equivalently, if `C=im V` and

```math
\mu_V(c)=\min\{|z|:Vz=c\},                    \tag{MR.3}
```

then

```math
F_V(u)=\min_{c\in C}\bigl(2\mu_V(c)+|u+c|\bigr). \tag{MR.4}
```

Put

```math
\mathcal A_V=\{v_j:|v_j|\ge3\},               \tag{MR.5}
```

where repetitions are discarded.  Then `F_V` is determined exactly by
`A_V`, and it recovers that set by

```math
\boxed{\mathcal A_V=\{u\in W:|u|\ge3, F_V(u)=2\}.} \tag{MR.6}
```

Consequently

```math
F_V=F_{V'}\quad\Longleftrightarrow\quad
\mathcal A_V=\mathcal A_{V'}.                 \tag{MR.7}
```

#### Proof

Choosing `z` specifies the cost-two generators, and the unique cheapest
coordinate correction has weight `|u+Vz|`.  This proves (MR.2)--(MR.4).
Repeated copies of a generator are never both needed.  A generator of
Hamming weight at most two can be replaced by coordinate generators at no
greater cost, so `A_V` determines `F_V`.

Conversely fix `u` with `|u|>=3`.  If `F_V(u)<=2`, the empty choice is
impossible.  A choice of at least two channels already costs four.  Thus
exactly one channel is chosen and its residual has weight zero, so `u` is
a column of `V`.  Every heavy column gives value exactly two, proving
(MR.6) and (MR.7). `square`

If exactly `k` input slots are allowed, their number of distinct exact
profiles is therefore

```math
\sum_{j=0}^{\min\{k,N_D\}}{N_D\choose j},
\qquad
N_D=2^D-\sum_{i=0}^2{D\choose i}.              \tag{MR.8}
```

This already locates the genuine invariance.  Channel permutations,
duplicates, and columns of weight at most two are invisible.  A general
change of basis in `F_2^k` is **not** an invariance because the coefficient
weight `|z|` in (MR.1) is basis dependent.

For example, partition `D=3t` coordinates into three blocks of size `t`
and take

```math
a=(1,0,1),\qquad b=(0,1,1)                    \tag{MR.9}
```

in block notation.  For `t>=2`, the two bases `(a,b)` and `(a,a+b)` of the
same two-dimensional code obey

```math
F_{(a,b)}(b)=2,
\qquad
F_{(a,a+b)}(b)=4.                              \tag{MR.10}
```

Thus quotienting full-rank matrices on the right by `GL(k,2)` forgets real
exact response information.  It becomes an approximate quotient only at
a scale on which the coefficient cost below is negligible.

## 2. The span is a controlled macroscopic quotient

For a linear code `C subseteq W`, write

```math
d_C(u)=\min_{c\in C}|u+c|.                    \tag{MR.11}
```

### Lemma MR.2 (span sandwich)

If `r=rank V` and `C=im V`, then pointwise

```math
\boxed{d_C(u)\le F_V(u)\le d_C(u)+2r.}        \tag{MR.12}
```

In particular the upper error is at most `2k`.

#### Proof

Dropping the nonnegative coefficient cost in (MR.4) proves the lower
bound.  Choose `r` independent columns of `V`.  Every nearest `c in C` has
a representation using at most those `r` columns, so substituting it in
(MR.4) proves the upper bound. `square`

For arbitrary nonempty subsets of a metric space, the uniform distance
between their distance functions equals their Hausdorff distance.  Lemma
MR.2 therefore says that, for `r=o(D)`, the ordinary code `C` controls the
normalized profile up to `o(1)`.  This is only a macroscopic statement:
MR.1 shows that it is false exactly.

## 3. A `Dk`-bit macroscopic packing

Let `H_2` denote binary entropy.  Fix constants

```math
0<\delta<\tfrac12,
\qquad
0<\rho<1-H_2(\delta).                         \tag{MR.13}
```

The binary linear Gilbert--Varshamov argument gives, for all sufficiently
large `D`, a code

```math
C_0\le\mathbb F_2^D,
\qquad
\dim C_0=r\ge\rho D,
\qquad
d(C_0)\ge\delta D-o(D).                       \tag{MR.14}
```

The weaker assertion along an infinite sequence is already enough below.

### Theorem MR.3 (unlabeled multichannel response packing)

For every `k<=r`, choose one arbitrary ordered basis `V_C` for each
`k`-dimensional subspace `C<=C_0`, and let `F_C=F_{V_C}`.  Then

```math
\#\{F_C:C\le C_0,\ \dim C=k\}
={r\brack k}_2
\ge2^{k(r-k)},                                 \tag{MR.15}
```

and distinct members satisfy

```math
\boxed{
\|F_C-F_{C'}\|_\infty
\ge d(C_0)-2k.}                               \tag{MR.16}
```

Consequently, if a deterministic summary permits reconstruction of the
entire kernel profile to uniform additive error `epsilon D` and

```math
d(C_0)-2k>2\epsilon D,                        \tag{MR.17}
```

then its range on this family has at least `2^{k(r-k)}` elements.  It
requires at least

```math
k(r-k)                                        \tag{MR.18}
```

bits.

#### Proof

For large `D`, every nonzero member of `C_0` has weight at least three.
Thus MR.1 recovers the chosen basis set from `F_C`; equal profiles would
give equal basis sets and hence equal subspaces.  This proves the equality
in (MR.15).

Take distinct `C,C'` and choose `c in C\C'`.  For every `c' in C'`, the
word `c+c'` is a nonzero member of `C_0`; hence

```math
d(c,C')\ge d(C_0).                             \tag{MR.19}
```

The chosen basis of `C` represents `c` with at most `k` columns, so

```math
F_C(c)\le2k.
```

On the other hand, Lemma MR.2 gives

```math
F_{C'}(c)\ge d_{C'}(c)\ge d(C_0).
```

This proves (MR.16), independently of every basis choice.  The Gaussian
binomial coefficient counts the subspaces.  From its product formula,

```math
{r\brack k}_2
=\prod_{i=0}^{k-1}{2^r-2^i\over2^k-2^i}
\ge2^{k(r-k)},                                 \tag{MR.20}
```

because each normalized numerator factor is at least its denominator
factor.  Finally, two profiles decoded from the same summary state would
be at uniform distance at most `2 epsilon D`, contradicting (MR.16) under
(MR.17). `square`

For any fixed `epsilon<1/4`, first choose `delta` with
`2epsilon<delta<1/2`, then `rho<1-H_2(delta)`, and finally any constant

```math
0<\alpha<\min\{\rho,(\delta-2\epsilon)/2\}.   \tag{MR.21}
```

Taking `k=floor(alpha D)` proves an `Omega(Dk)=Omega(D^2)` information
lower bound at distortion `epsilon D`.  The same proof gives
`Omega(Dk)` for every smaller `k`, including fixed `k`.  Exact storage of
the columns uses `Dk` bits, so the order is sharp in this regime.

The condition `epsilon<1/4` is a range of this construction, not a claimed
universal threshold.

## 4. Why the queries are genuinely unlabelled

Let `Q=F_2^k` have basis `q_1,...,q_k`, and form two fragments

```math
P=\{(0,q_j):1\le j\le k\},
\qquad
R_V=\{(v_j,q_j):1\le j\le k\}.                \tag{MR.22}
```

Together with the kernel coordinate basis `B`, a quotient-zero word must
select either both members of the `j`th pair or neither.  Therefore

```math
\ell_{B\cup P\cup R_V}(u,0)=F_V(u).           \tag{MR.23}
```

Each fragment separately has independent quotient columns.  It has no
internal cycle, and a kernel-fixing shear removes all of its offsets.  Thus
all information in `V` is relative gluing information born at composition.
The decoder in MR.3 sees only endpoints `(u,0)` in the kernel layer; it is
never allowed to ask which channel generated a response.

The quotient basis supplies a structural matching between the two input
fragments, but no labels occur in the query class.  Automorphisms preserving
the atom set `P` give only channel permutations.  Arbitrary `GL(k,2)` basis
changes do not preserve the cost-two atom set and, as (MR.10) shows, should
not be divided out.  Even if one deliberately forgets all basis-dependent
information and retains only `span V`, the packing in MR.3 survives: it
already has one representative for each of `{r bracket k}_2` different
subspaces.

## 5. Upper nets and limitations

The packing does not assert `Omega(Dk)` for arbitrary `k`.  Proposition
MR.1 gives at most `2^{N_D}` exact profiles regardless of the number of
input slots.  More generally, every `F_V` is one-Lipschitz on the Hamming
cube and takes values in `[0,D]`.  If `U` is a Hamming `eta D`-net of the
cube, recording `F_V` on `U` to mesh `eta D` determines it uniformly to
`2eta D`.  Standard covering codes give such a description using

```math
2^{(1-H_2(\eta)+o(1))D}\,O(\log(1/\eta))       \tag{MR.24}
```

bits, independent of `k`.  Thus linear growth in `Dk` must eventually
saturate when the channel count itself is exponentially large.

In the regime `k<=alpha D` of MR.3 there is no contradiction: the trivial
exact column description is `O(Dk)` bits and the theorem gives a matching
lower order.  The result identifies a genuine intermediate law:

> each independent mixed channel can contribute a new `Theta(D)`-bit
> macroscopic response direction until either its coefficient cost becomes
> comparable with the target distortion or the ambient response space
> saturates.

This is stronger than counting exact gauge classes.  It proves that a
positive fraction of those algebraic degrees of freedom remain separated
after projection to one unlabelled family of extremal queries.

## 6. Scope and relation to existing theory

Equation (MR.4) is weighted syndrome decoding / a weighted Cayley metric,
and (MR.14) is the classical linear Gilbert--Varshamov construction.  The
new project deduction is their use in the mixed-fragment exact sequence:
locally pure-gauge fragments generate `Dk` relative alignment bits, and
MR.3 shows that kernel-only extremal responses retain `Omega(Dk)` of them
at fixed macroscopic distortion.

This is not a universal theorem that every algebraic feature survives a
query class.  It supplies a verifiable sufficient mechanism: a large
minimum-distance host code converts distinct feature subspaces into
Hausdorff-separated zero sets, while the generator penalty costs only
`2k`.  It applies equally to weighted Cayley metrics, systematic-code
coset-leader profiles, and shortest-path responses in binary group
extensions.
