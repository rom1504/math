# Benchmark: weighted-automaton response compression

**Status.** Rigorous benchmark draft.  The operational derivation was made
before comparison with weighted Nerode/Hankel theory.  The exact residual
quotient is classical in that language.  The query-relative entropy
sandwich, its affine-dimension falsifier, and the explicit repeatedly closed
tropical aggregation are the response-theoretic additions tested here.

All weights below are finite real numbers and `max-plus` notation is used.
Changing signs gives the min-plus version.

## 1. The experiment forces residual responses

Let `T_a` be `p by p` max-plus transition matrices, with initial row
`alpha` and terminal column `beta`.  For prefix `x` and suffix `y`, put

```math
p_x=\alpha\odot T_x,
\qquad h_y=T_y\odot\beta .                         \tag{WA.1}
```

Then

```math
L(xy)=\max_i\{p_x(i)+h_y(i)\}.                    \tag{WA.2}
```

Fix a declared suffix language `Y` and let two prefixes be equivalent when
every suffix in `Y` gives the same value.

### Proposition WA.1 (coarsest quotient and derivative algebra)

The coarsest exact contextual state is

```math
\rho_x:Y\to\mathbb R,
\qquad \rho_x(y)=L(xy).                            \tag{WA.3}
```

Equivalently,

```math
p\sim_Yq
\Longleftrightarrow
\max_i(p_i+h_y(i))=\max_i(q_i+h_y(i))
\quad\hbox{for all }y\in Y.                       \tag{WA.4}
```

If `Y` is closed under prepending allowed words, concatenation acts by

```math
(D_u\rho)(y)=\rho(uy),
\qquad D_vD_u=D_{uv}.                              \tag{WA.5}
```

For `d_Y(rho,sigma)=sup_Y|rho-sigma|`, every derivative is nonexpansive.

#### Proof

A residual answers every declared future query.  Conversely, a suffix at
which two residuals differ distinguishes them, proving minimality.  Finally,

```math
\rho_{xu}(y)=L(xuy)=\rho_x(uy),                    \tag{WA.6}
```

which proves the algebra and nonexpansiveness. `square`

This derivation predicts a weighted residual rather than the raw forward
vector.  The collision with weighted Myhill--Nerode theory is exact and is
not claimed as new.  What remains nonclassical in this benchmark is the
uniform approximate complexity of the residual family under a declared
suffix metric.

## 2. Query geometry versus robust exposure

For a suffix-vector family `H subset R^p`, define

```math
F_p(h)=\max_i(p_i+h_i),
\qquad
d_H(p,q)=\sup_{h\in H}|F_p(h)-F_q(h)|.             \tag{WA.7}
```

A common translation of `h` is a known query baseline, so use projective
query distance

```math
d_{\rm pr}(h,k)=\inf_c\|h-k-c\boldsymbol1\|_\infty. \tag{WA.8}
```

Let `N_pr(delta;H)` be its covering number and let `R_B(H)` be the residuals
generated by `p in [-B,B]^p`.

### Theorem WA.2 (response-entropy sandwich)

For `delta,eta>0`, external covering numbers satisfy

```math
\log_2N^{\rm ext}_{\delta+\eta/2}(\mathcal R_B(H))
\le
N_{\rm pr}(\delta;H)
\log_2\left(\left\lceil{2B\over\eta}\right\rceil+2\right). \tag{WA.9}
```

Also

```math
\log_2N_\epsilon(\mathcal R_B(H))
\le p\log_2(1+2B/\epsilon).                       \tag{WA.10}
```

In the opposite direction, suppose suffixes `h^(1),...,h^(k)` expose
distinct coordinates `i_1,...,i_k` with margin `2B`:

```math
h^{(j)}_{i_j}\ge\max_{i\ne i_j}h^{(j)}_i+2B.     \tag{WA.11}
```

On the subfamily in which those coordinates vary independently and all
other coordinates are fixed, the response map is an isometric
`[-B,B]^k` sup-norm cube.  Hence that subfamily has

```math
\log_2N_\epsilon
=\Theta\bigl(k\log(1+B/\epsilon)\bigr).           \tag{WA.12}
```

and the same expression is a lower bound for the full residual class.

#### Proof

Choose a projective `delta`-net `k_1,...,k_m`.  At each `k_j`, `F_p(k_j)`
ranges over an interval of length `2B`; quantize it with mesh `eta`.  If
`||h-k_j-c1||_infty<=delta`, add the known baseline `c` to the stored value.
The maximum is one-Lipschitz, giving error `delta+eta/2` and (WA.9).
Quantizing `p` proves (WA.10).

Under (WA.11), query `h^(j)` returns exactly
`p_(i_j)+h^(j)_(i_j)`.  Thus the response metric equals the sup metric on
the exposed-coordinate cube.  Grid packing and covering prove (WA.12).
`square`

If normalized suffix vectors lie in a radius-`R` subset of a
`d`-dimensional affine space, volumetric covering gives

```math
N_{\rm pr}(\delta;H)\le(1+2R/\delta)^d.            \tag{WA.13}
```

This is scale-sensitive: affine dimension by itself is false as a
compression certificate.

### Example WA.1 (a one-dimensional family exposes every coordinate)

For `t=1,...,p`, let

```math
h(t)_i=C(2it-i^2),\qquad C\ge2B.                  \tag{WA.14}
```

All `h(t)` lie on the affine line `b+ta`, but

```math
h(j)_j-h(j)_i=C(j-i)^2\ge2B\quad(i\ne j).         \tag{WA.15}
```

Thus all `p` coordinates are exposed and the cost is
`Theta(p log(1+B/epsilon))`.  The line's projective diameter and its covering
number at the relevant scale grow with `p`; (WA.9), unlike bare affine
dimension, detects this.

## 3. A strict quotient closed under arbitrary concatenation

Partition raw states into nonempty blocks
`[p]=I_1 disjoint-union ... disjoint-union I_r`, and choose gauges `c_i`.
Assume that for every letter `ell`, source block `a`, target block `b`, and
`i in I_a`,

```math
\max_{j\in I_b}\{T_\ell(i,j)+c_j\}-c_i
=S_\ell(a,b),                                     \tag{WA.16}
```

independent of the microscopic source `i`.  Assume also

```math
\beta_i=c_i+u_\varnothing(a)\qquad(i\in I_a).     \tag{WA.17}
```

### Theorem WA.3 (tropical lumpability)

Every suffix vector factors as

```math
h_y(i)=c_i+u_y(a),
\qquad
u_{\ell y}(a)=\max_b\{S_\ell(a,b)+u_y(b)\}.       \tag{WA.18}
```

The nonlinear aggregate

```math
P_a=\max_{i\in I_a}\{p_i+c_i\}                   \tag{WA.19}
```

answers every suffix and updates exactly by

```math
F_p(h_y)=\max_a\{P_a+u_y(a)\},                   \tag{WA.20}
```

```math
P'_b=\max_a\{P_a+S_\ell(a,b)\}.                 \tag{WA.21}
```

Consequently `p` raw coordinates quotient to `r` max-plus coordinates under
arbitrarily many concatenations, with no accumulated error.

If the quotient suffix family contains, for every `a`, a vector satisfying

```math
u^{(a)}_a\ge\max_{b\ne a}u^{(a)}_b+2B,           \tag{WA.22}
```

then the formal response family on `P in [-B,B]^r` is minimal and has the
matching rate

```math
\log_2N^{\rm ext}_\epsilon
=\Theta\bigl(r\log(1+B/\epsilon)\bigr).           \tag{WA.23}
```

For a fixed automaton, this conclusion applies to its reachable aggregate
set.  The full cube rate requires that prefixes reach this box, or a
comparable product packing.

#### Proof

Induct (WA.18) from (WA.17), grouping target states by blocks and applying
(WA.16).  Grouping the response maximum proves (WA.20).  For an appended
letter,

```math
\begin{aligned}
P'_b
&=\max_{j\in I_b}\max_i\{p_i+T_\ell(i,j)+c_j\}\\
&=\max_a\max_{i\in I_a}\{p_i+c_i+S_\ell(a,b)\},
\end{aligned}                                     \tag{WA.24}
```

which is (WA.21).  Under (WA.22), the `a`th pin query returns
`P_a+u^(a)_a`; hence all aggregate coordinates are recovered.  Cube packing
and covering prove (WA.23). `square`

### Example WA.2 (four different rows compress to two states)

Let `I_0={1,2}`, `I_1={3,4}` and `c=0`.  Lift any `2 by 2` quotient matrix
`S` by

```math
T^S_{ij}=S_{ab}+\eta_{ij}
\quad(i\in I_a,j\in I_b),                         \tag{WA.25}
```

where within either target block the two `eta` entries are `(0,-1)` for
source states `1,3`, and `(-2,0)` for source states `2,4`.  All four rows
of each displayed lifted matrix below are different, but each target-block
maximum of `eta` is zero, so (WA.16) holds.  Use

```math
S_A=\begin{pmatrix}0&-2\\-1&1\end{pmatrix},
\qquad
S_B=\begin{pmatrix}-1&0\\2&-2\end{pmatrix}.      \tag{WA.26}
```

With `beta=0`, the exact state is

```math
(P_0,P_1)=(\max(p_1,p_2),\max(p_3,p_4)).          \tag{WA.27}
```

Two additional quotient letters with row maxima `(K,0)` and `(0,K)` expose
the coordinates for `K>=2B`.  Neither microscopic state in a block can be
deleted uniformly: which one supplies its maximum depends on the incoming
vector.  The quotient is therefore a strict nonlinear aggregate, not a
boundary-assignment table or a disguised selection of two raw coordinates.

## 4. Affine suffixes yield an upper-hull carrier

Suppose the suffix vectors have the form

```math
h(\theta)_i=b_i+\langle a_i,\theta\rangle,
\qquad\theta\in\Theta\subset\mathbb R^d.          \tag{WA.28}
```

Define

```math
K_p=\operatorname {conv}
\{(a_i,p_i+b_i):i\in[p]\}\subset\mathbb R^{d+1}. \tag{WA.29}
```

### Proposition WA.4 (visible upper hull and affine continuation)

The residual is the restricted support function

```math
F_p(h(\theta))=h_{K_p}((\theta,1)).                \tag{WA.30}
```

Thus the exact contextual state is the upper hull visible in directions
`{(theta,1):theta in Theta}`; permanently unexposed raw pieces disappear.
If prepending `u` acts by

```math
\tau_u(\theta)=M_u\theta+t_u,
\qquad h_{uy}=h(\tau_u\theta_y),                  \tag{WA.31}
```

then derivatives close by pushing carrier points through

```math
(a,v)\longmapsto(M_u^Ta,v+\langle a,t_u\rangle).  \tag{WA.32}
```

#### Proof

Equation (WA.30) is the definition of a support function.  Substitution of
(WA.31) changes
`<a,theta>+v` into `<M_u^Ta,theta>+v+<a,t_u>`, proving (WA.32). `square`

This carrier can have far fewer exposed vertices than raw states and is
another non-boundary composable state.  Its support-function description is
the convex-geometric dual of the shared-parameter max-affine arrangement
lemma used elsewhere in this campaign; that collision should be recorded,
not advertised as a separate invention.

## 5. Classical collisions and genuinely quantitative content

The infinite table `H_L(x,y)=L(xy)` is the weighted Hankel table.  Its
restricted rows are exactly Proposition WA.1's residuals.  Stable residual
semimodules and weighted Nerode constructions are standard, so neither the
name nor the exact row quotient is a novelty claim.

Over fields, Hankel rank and SVD-based approximate minimization measure
linear realizability and spectral or `ell_2` error.  Those results do not
give (WA.9)--(WA.12): uniform error over declared suffixes is sensitive to a
single exposed query, and max-plus has no cancellation by subtraction.

The response framework adds a useful three-way separation:

```math
\begin{array}{c|c}
\text{quantity}&\text{what controls it}\\
\hline
\text{raw presentation size}&p\text{ automaton coordinates}\\
\text{exact composable state}&\text{derivative congruence / visible carrier}\\
\text{approximate response information}&
\text{suffix metric entropy versus robust exposure}
\end{array}                                       \tag{WA.33}
```

Theorem WA.3 validates that this distinction can predict a strict state and
its sharp rate rather than merely rename transfer matrices.  Example WA.1
is the necessary falsifier: low-dimensional notation without bounded query
geometry can still retain the full raw response information.

## 6. Verification and next question

[`verify_weighted_automaton_response.py`](../experiments/verify_weighted_automaton_response.py)
checks exactly:

1. the lifted four-state matrices satisfy (WA.16);
2. forward aggregation commutes with every displayed letter on an exhaustive
   integer box;
3. raw and quotient suffix responses agree through bounded word depth;
4. the two query letters expose the two aggregate coordinates; and
5. the affine-line construction exposes every raw coordinate.

The strongest next theorem is to close the remaining gap between (WA.9) and
(WA.12): characterize uniform residual entropy by a scale-dependent
exposed-face dimension, and determine when its approximate quotient admits a
nonaccumulating finite derivative algebra.
