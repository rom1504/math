# Wave 40 boundary: blank-slate candidate generation

This stage uses only the original problem

```math
M_n=\min_{a_{ij}\in\{\pm1\}}
\max_{x_i\in\{\pm1\}}
\left|\sum_{i<j}a_{ij}x_ix_j\right|,
\qquad
\text{does }M_n/n^{3/2}\text{ converge?}
```

No comparison with the research ledger is made in this file.  The candidates
are hypotheses generated by the main agent, not user objectives.

## Candidate A: finite-pressure thermodynamic limit

For a signing `A`, write `H_A(x)=sum_(i<j)a_(ij)x_ix_j` and define, for fixed
`b>0`,

```math
\Phi_n(b)
=\frac1n\min_A
\log\left(
2^{-n}\sum_{x\in\{\pm1\}^n}
2\cosh\frac{bH_A(x)}{\sqrt n}
\right).
\tag{A1}
```

This maps the original maximum exactly to a zero-temperature limit.  If
`m_n=M_n/n^(3/2)`, the largest summand and the total number of summands give

```math
b m_n-\log2
\le\Phi_n(b)
\le b m_n+\frac{\log2}{n}.
\tag{A2}
```

Concrete theorem sought:

```math
\boxed{
\text{For every fixed }b>0,
\quad \lim_{n\to\infty}\Phi_n(b)=\Phi(b)\text{ exists.}
}
\tag{A3}
```

Indeed (A2) would imply

```math
\limsup m_n-\liminf m_n\le\frac{\log2}{b}
```

for every `b`, and sending `b` to infinity proves convergence.  A plausible
proof mechanism would be an interpolation or approximate-subadditivity
inequality for the **optimized** finite-pressure functional, with an error
`o(n)` at fixed `b`.  The important content is existence of the fixed-`b`
limit before taking zero temperature; merely defining (A1) is not progress.

## Candidate B: a deep-hole product for the augmented cut code

Encode a signing as an edge word on `K_n`.  Vertex switching and global
complement form the augmented cut code `C_n`, and exactly

```math
M_n=N_n-2\rho(C_n),
\qquad N_n=\binom n2.
\tag{B1}
```

Put `D_n=N_n/2-rho(C_n)=M_n/2`.  The concrete composition theorem is:

```math
\boxed{
D_{kn}\le k^{3/2}D_n+\varepsilon_n(kn)^{3/2},
\qquad \varepsilon_n\longrightarrow0,
}
\tag{B2}
```

uniformly for large integers `k`, together with the already elementary
transfer from multiples to nearby orders.  Equivalently,

```math
M_{kn}\le k^{3/2}M_n+o((kn)^{3/2}).
```

Taking `n` along a subsequence realizing the liminf would force the limsup
below the same value and prove convergence.

The proposed mechanism is a genuine code product: start from a deepest edge
word on `K_n`, replace each vertex by `k` vertices, and decorate within and
between clusters by balanced orthogonal sign gadgets.  The theorem must show
that **every** cut of the blow-up loses at most the root-sum-square deficit in
(B2).  A scalar block copy is not enough; (B2) is the testable statement.

## Candidate C: exchange control of the discrete homogeneity defect

Let `q_n=2M_n`.  Exact homogeneity of order `3/2` would have increment
`(3/2)q_n/n`.  Define

```math
e_n=q_n-q_{n-1}-\frac{3q_n}{2n}.
\tag{C1}
```

The concrete exchange theorem is

```math
\boxed{|e_n|\le Cn^{1/2-\delta}}
\tag{C2}
```

for some fixed `delta>0`, or the weaker summable form

```math
\sum_{r=n}^{2n}\frac{|e_r|}{r^{3/2}}=o(1)
\quad\text{uniformly on dyadic windows.}
\tag{C3}
```

The exact mapping follows by expanding
`q_n/n^(3/2)-q_(n-1)/(n-1)^(3/2)`: (C2) makes these normalized increments
`O(n^(-1-delta))` up to a summable Taylor remainder, while (C3) makes every
dyadic normalized oscillation vanish.  Either proves convergence.

The intended mechanism is a two-sided vertex exchange theorem: deletion from
an order-`n` optimizer and insertion into an order-`n-1` optimizer should have
matching marginal costs up to `O(n^(1/2-delta))`.  A statement about the
numerical sequence alone would only rename the goal; progress requires an
exact signing-level exchange identity or coupling that proves (C2)/(C3).
