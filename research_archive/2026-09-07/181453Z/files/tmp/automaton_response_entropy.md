# Weighted automata as a response-compression benchmark

**Status.** Independent benchmark report.  The response quotient, entropy
bounds, lumpability theorem, and examples below were derived before the
literature comparison in Section 7.  All weights are finite real numbers and
the max-plus convention is used.  The min-plus statements follow by changing
signs.

## 1. Operational setup and the exact quotient

Let `Sigma` be an alphabet, let `T_a` be `p by p` max-plus transition
matrices, and let `alpha,beta in R^p`.  Write

```math
(u\mathbin\odot T)_j=\max_i(u_i+T_{ij}),
\qquad
(T\mathbin\odot v)_i=\max_j(T_{ij}+v_j).
```

For a prefix `x` and a suffix `y`, define

```math
p_x=\alpha\mathbin\odot T_x,
\qquad
h_y=T_y\mathbin\odot\beta .                       \tag{1.1}
```

Then the value of the concatenated word is

```math
L(xy)=\max_i\{p_x(i)+h_y(i)\}.                    \tag{1.2}
```

Fix a declared suffix language `Y`.  Two prefixes are contextually
equivalent when they have the same value after every suffix in `Y`.

### Theorem 1 (coarsest contextual state and exact derivative algebra)

The coarsest exact state of a prefix is its residual response

```math
\rho_x:Y\longrightarrow\mathbb R,
\qquad
\rho_x(y)=L(xy).                                   \tag{1.3}
```

Equivalently, on forward vectors the quotient is

```math
p\sim_Y q
\quad\Longleftrightarrow\quad
\max_i(p_i+h_y(i))=\max_i(q_i+h_y(i))
\quad\hbox{for every }y\in Y.                     \tag{1.4}
```

If `Y` is closed under prepending every allowed continuation `u`, the exact
transition on quotient states is

```math
(D_u\rho)(y)=\rho(uy),
\qquad
D_vD_u=D_{uv}.                                     \tag{1.5}
```

For the uniform response metric

```math
d_Y(\rho,\rho')=\sup_{y\in Y}|\rho(y)-\rho'(y)|,  \tag{1.6}
```

every derivative is nonexpansive:

```math
d_Y(D_u\rho,D_u\rho')\le d_Y(\rho,\rho').         \tag{1.7}
```

#### Proof

Equation (1.3) is sufficient by definition of a future context.  If two
states have different residuals, a suffix at which they differ distinguishes
them, so no coarser state is sufficient.  Finally,

```math
\rho_{xu}(y)=L(xuy)=\rho_x(uy),                   \tag{1.8}
```

which proves (1.5); taking a supremum over the subset `uY` of `Y` proves
(1.7).  `square`

Thus the raw forward vector is generally not minimal.  The quotient is not
postulated from an automaton representation: it is forced by the declared
future experiment.  Notice also that an exact residual set can be infinite
even though the presented automaton has finitely many raw states.

## 2. A quantitative response-entropy sandwich

For a set `H subset R^p` of reachable suffix vectors put

```math
F_p(h)=\max_i(p_i+h_i),
\qquad
d_H(p,q)=\sup_{h\in H}|F_p(h)-F_q(h)|.             \tag{2.1}
```

Common translation of a suffix vector is a known context-dependent baseline.
The natural query geometry is therefore

```math
d_{\rm pr}(h,k)=\inf_{c\in\mathbb R}
                 \|h-k-c\boldsymbol1\|_\infty.   \tag{2.2}
```

Let `N_pr(delta;H)` denote its covering number.  Let `R_B(H)` be the residual
class generated by all `p in [-B,B]^p`.

### Theorem 2 (query-cover upper bound)

For every `delta,eta>0`,

```math
\log_2 N_{\delta+\eta/2}
  (\mathcal R_B(H),\|\cdot\|_\infty)
\le
N_{\rm pr}(\delta;H)
\log_2\left(\left\lceil{2B\over\eta}\right\rceil+2\right).    \tag{2.3}
```

There is also the representation bound

```math
\log_2 N_\epsilon(\mathcal R_B(H),\|\cdot\|_\infty)
\le p\log_2(1+2B/\epsilon).                        \tag{2.4}
```

#### Proof

Choose a projective `delta`-net `k_1,...,k_m` in `H`.  At a fixed `k_j`, as
the forward vector ranges over the box,

```math
F_p(k_j)\in[\max_i k_j(i)-B,\max_i k_j(i)+B].      \tag{2.5}
```

Quantize each of the `m` values with mesh `eta`; this gives the right-hand
side of (2.3).  Given `h`, choose `j` and `c` with
`||h-k_j-c1||_infty<=delta`.  The decoder adds the known baseline `c` to the
quantized value at `k_j`.  Since a maximum is one-Lipschitz in the sup norm,
the total error is at most `delta+eta/2`.  Quantizing the `p` forward
coordinates and using the same one-Lipschitz fact proves (2.4).  `square`

### Corollary 2.1 (bounded low-dimensional suffix geometry)

Suppose normalized representatives of `H` lie in a radius-`R` subset of a
`d`-dimensional affine subspace, with the inherited sup norm.  A volumetric
net gives

```math
N_{\rm pr}(\delta;H)\le(1+2R/\delta)^d.            \tag{2.6}
```

In particular, taking `delta=epsilon/2` and `eta=epsilon` yields

```math
\log_2N_\epsilon(\mathcal R_B(H))
\le
(1+4R/\epsilon)^d
\log_2(\lceil2B/\epsilon\rceil+2),                 \tag{2.7}
```

independently of the raw state count `p`.

The dimension by itself is not enough.  Both a normalized diameter bound and
the metric scale matter, as the next theorem and example show.

### Theorem 3 (robustly exposed suffixes force information)

Suppose there are distinct coordinates `i_1,...,i_k` and suffix vectors
`h^(1),...,h^(k)` such that

```math
h^{(j)}_{i_j}\ge
\max_{i\ne i_j}h^{(j)}_i+2B.                       \tag{2.8}
```

On the subfamily in which only the `k` exposed coordinates vary in
`[-B,B]`, the map from forward vectors to residuals is an isometric embedding
of the `k`-dimensional sup-norm cube.  Consequently, for `0<epsilon<B`,

```math
\log_2N_\epsilon(\mathcal R_B(H))
=\Theta\bigl(k\log(B/\epsilon)\bigr),             \tag{2.9}
```

with absolute constants in the elementary covering/packing bounds.

#### Proof

At query `h^(j)`, condition (2.8) makes coordinate `i_j` a maximizer for
every forward vector in the box, even in the worst possible `2B` swing.
Therefore

```math
F_p(h^{(j)})=p_{i_j}+h^{(j)}_{i_j}.                \tag{2.10}
```

The response metric is at least the sup distance on the exposed
coordinates, while the one-Lipschitz upper bound gives the reverse
inequality.  Standard grid packing and covering of `[-B,B]^k` prove (2.9).
`square`

### Example 1 (affine dimension one can expose all `p` coordinates)

Fix `C>=2B` and, for `t=1,...,p`, define a suffix vector by

```math
h(t)_i=C(2it-i^2).                                 \tag{2.11}
```

The vectors all lie on the affine line `h(t)=b+ta`.  Nevertheless,

```math
h(j)_j-h(j)_i=C(j-i)^2\ge2B\qquad(i\ne j),        \tag{2.12}
```

so Theorem 3 gives the full `Theta(p log(B/epsilon))` response cost.  The
projective diameter of this line segment is growing (of order `Bp^2` in this
normalization), and its query covering number at the exposure scale is at
least `p`.  Thus “suffix affine dimension `1`” is not a compression theorem;
Theorem 2 uses the correct scale-sensitive geometry.

Together, Theorems 2 and 3 give a useful general sandwich:

```math
\text{robust coordinate exposure}
\ \le\ \text{response information}
\ \le\ \text{metric entropy of the declared suffix queries}. \tag{2.13}
```

## 3. A strict, repeatedly composable quotient

The preceding bounds concern arbitrary suffix geometry.  The following
finite identity gives an exact compressed automaton.

Partition the raw states into nonempty blocks

```math
[p]=I_1\sqcup\cdots\sqcup I_r
```

and choose gauges `c_i`.  Assume that for every letter `ell`, source block
`a`, target block `b`, and every `i in I_a`,

```math
\max_{j\in I_b}\{T_\ell(i,j)+c_j\}-c_i
=S_\ell(a,b),                                      \tag{3.1}
```

where the right-hand side is independent of the microscopic source `i`.
Assume also

```math
\beta_i=c_i+u_\varnothing(a)\qquad(i\in I_a).     \tag{3.2}
```

### Theorem 4 (tropical lumpability and exact repeated closure)

Every suffix vector factors as

```math
h_y(i)=c_i+u_y(a)\qquad(i\in I_a),                 \tag{3.3}
```

where

```math
u_{\ell y}(a)=\max_b\{S_\ell(a,b)+u_y(b)\}.       \tag{3.4}
```

For an arbitrary forward vector, retain only the `r` tropical aggregates

```math
P_a=\max_{i\in I_a}\{p_i+c_i\}.                   \tag{3.5}
```

Then every suffix response and every appended-letter update are computed by

```math
F_p(h_y)=\max_a\{P_a+u_y(a)\},                    \tag{3.6}
```

```math
P'_b=\max_a\{P_a+S_\ell(a,b)\}.                  \tag{3.7}
```

Hence a nonlinear `p`-coordinate forward vector quotients exactly to an
`r<p` coordinate max-plus state, and the quotient closes under arbitrarily
many concatenations with no accumulated loss.

#### Proof

Equation (3.3) holds for the empty suffix by (3.2).  If it holds for `y`,
then (3.1) gives

```math
h_{\ell y}(i)
=\max_b\max_{j\in I_b}
 \{T_\ell(i,j)+c_j+u_y(b)\}
=c_i+\max_b\{S_\ell(a,b)+u_y(b)\},                \tag{3.8}
```

proving the induction and (3.4).  Equation (3.6) follows by grouping the
maximum in (1.2).  If `p'=p odot T_ell`, then

```math
\begin{aligned}
P'_b
&=\max_{j\in I_b}\max_i\{p_i+T_\ell(i,j)+c_j\}\\
&=\max_a\max_{i\in I_a}
 \{p_i+c_i+S_\ell(a,b)\}\\
&=\max_a\{P_a+S_\ell(a,b)\},
\end{aligned}                                      \tag{3.9}
```

which proves exact closure.  `square`

### Theorem 5 (matching rate--distortion for an exposed quotient)

Restrict the aggregate vector to `[-B,B]^r`.  If the quotient suffix family
contains, for every `a`, a vector `u^(a)` satisfying

```math
u^{(a)}_a\ge\max_{b\ne a}u^{(a)}_b+2B,            \tag{3.10}
```

then the aggregate map (3.5) is the coarsest exact state on this box and

```math
\log_2N_\epsilon
=\Theta\bigl(r\log(B/\epsilon)\bigr)              \tag{3.11}
```

for uniform suffix-response error.  The upper and lower exponents match.

#### Proof

Equation (3.6) proves sufficiency.  Query `u^(a)` returns
`P_a+u^(a)_a`, so all `r` coordinates are recovered and no further quotient
is possible.  The response metric on the aggregate box is exactly its sup
metric.  Cube packing and covering prove (3.11).  `square`

This is stronger than the statement that a table of boundary assignments is
sufficient.  The state (3.5) is a tropical, many-to-one aggregation of raw
coordinates; either microscopic member of a block can control it, and the
same aggregate is propagated algebraically forever.

### Example 2 (four genuinely different rows collapse to two aggregates)

Let `I_0={1,2}`, `I_1={3,4}`, and `c_i=0`.  Given any `2 by 2` quotient
matrix `S`, lift it by

```math
T^S_{ij}=S_{ab}+\eta_{ij}
\quad(i\in I_a,j\in I_b),                          \tag{3.12}
```

where, within either target block, the two `eta` entries are `(0,-1)` for
source states `1,3` and `(-2,0)` for source states `2,4`.  The four lifted
rows are different, but the maximum of the two `eta` entries is always zero,
so (3.1) holds.  For instance take dynamic letters

```math
S_A=\begin{pmatrix}0&-2\\-1&1\end{pmatrix},
\qquad
S_B=\begin{pmatrix}-1&0\\2&-2\end{pmatrix}.       \tag{3.13}
```

With `beta=0`, all suffix responses depend only on

```math
(P_0,P_1)=(\max(p_1,p_2),\max(p_3,p_4)).           \tag{3.14}
```

Add two query letters whose quotient matrices have constant rows `(K,0)`
and `(0,K)` after multiplication by `u_empty=(0,0)`.  For `K>=2B`, these
suffixes expose `P_0` and `P_1`, so Theorem 5 gives a sharp two-coordinate
state.  The compression is strict (`2<4`) and neither member of either pair
can simply be deleted in advance: which one supplies the aggregate depends
on the incoming forward vector.  A direct random check of (3.7) passed 1000
forward vectors for each displayed lifted transition.

## 4. Affine suffix geometry produces a convex carrier

There is a second strict quotient that need not arise from a partition.
Suppose the declared suffix vectors have a parameterization

```math
h(\theta)_i=b_i+\langle a_i,\theta\rangle,
\qquad \theta\in\Theta\subset\mathbb R^d.         \tag{4.1}
```

For a forward vector define the polytope

```math
K_p=\operatorname {conv}
\{(a_i,p_i+b_i):i\in[p]\}\subset\mathbb R^{d+1}. \tag{4.2}
```

### Theorem 6 (upper-hull quotient and affine continuation)

The residual is the restricted support function

```math
F_p(h(\theta))
=h_{K_p}((\theta,1))
=\max_i\{p_i+b_i+\langle a_i,\theta\rangle\}.     \tag{4.3}
```

Consequently the coarsest exact state is the upper hull of `K_p` visible in
the directions `{(theta,1):theta in Theta}`; all points never exposed in
these directions may be discarded.

Suppose, moreover, that prepending a word `u` acts on suffix parameters by
an affine map

```math
\tau_u(\theta)=M_u\theta+t_u,
\qquad h_{uy}=h(\tau_u(\theta_y)).                 \tag{4.4}
```

Then the residual derivative closes exactly on the carrier:

```math
(D_uF_p)(\theta)=F_p(\tau_u\theta),                \tag{4.5}
```

and `K_p` is pushed forward pointwise by

```math
(a,v)\longmapsto(M_u^Ta,v+\langle a,t_u\rangle).  \tag{4.6}
```

Repeated concatenation is therefore ordinary affine composition on a
convex carrier, not storage of the raw `p`-vector or a boundary-assignment
table.

#### Proof

Equation (4.3) is the definition of a support function.  Equality on all
declared directions is exactly contextual equivalence, proving the upper-hull
claim.  Substitution of (4.4) into (4.3) gives

```math
\langle a,M_u\theta+t_u\rangle+v
=\langle M_u^Ta,\theta\rangle+v+\langle a,t_u\rangle,  \tag{4.7}
```

which proves (4.5)--(4.6).  `square`

For example, arbitrarily many raw affine pieces can lie strictly below a
two-piece upper envelope on an interval.  The exact response state then has
two exposed carrier points although `p` is arbitrarily large.  If the suffix
semigroup acts by reflection and identity of the interval, those two points
remain an exact closed carrier under every continuation.  This is a second
non-boundary state, geometrically different from the block aggregate of
Theorem 4.

Theorem 2 supplies a dimension- and scale-sensitive approximate bound for
these carriers.  Uniformly bounded convex Lipschitz functions admit sharper
classical entropy bounds of order `epsilon^{-d/2}` in the logarithm; whether
a *fixed* slope alphabet `{a_i}` realizes the matching lower class is an
additional exposure question, not a consequence of affine dimension.

## 5. What the benchmark predicts rather than assumes

The response framework makes five checkable predictions here.

1. **The suffix family, not the raw presentation, chooses the state.**  The
   exact object is a row of the prefix--suffix response table restricted to
   declared suffixes.
2. **Exact concatenation is automatic on residuals but compression is not.**
   A smaller presented state must be a congruence for derivatives.  Condition
   (3.1) and affine action (4.4) are two concrete, qualitatively different
   mechanisms.
3. **Approximate complexity is query-relative.**  Theorem 2 prices the
   projective metric entropy of reachable suffix vectors.  A single robust
   suffix can matter even if it is statistically negligible.
4. **Low algebraic dimension is insufficient without scale control.**
   Example 1 has suffix affine dimension one and full `p`-coordinate response
   entropy.
5. **Matching lower bounds require exposure.**  Theorem 3 and condition
   (3.10) say exactly when future words can read independent retained
   coordinates.  This is the automaton analogue of exposed boundary states,
   but it was derived from response geometry rather than inserted as a DP
   table.

The genuinely quantitative conclusion is the sandwich (2.13), with the
sharp rate (3.11) on a repeatedly composable strict quotient.  This is not
obtained merely by renaming ordinary dynamic programming.

## 6. Failure modes and limits

* The exact residual can be as large as the whole reachable prefix set.  A
  finite raw automaton does not imply a finite contextual quotient over real
  weights.
* Affine span, tropical rank, or the number of raw states alone does not
  determine uniform response rate--distortion.  Exposure scale and query
  diameter are essential.
* Nonexpansiveness (1.7) prevents amplification of a once-made error, but
  rounding anew after every letter can still add its rounding errors.  Exact
  lumpability has no such accumulation.  A genuinely finite approximate
  automaton for arbitrary depth needs a stable quantizer or a strict
  contraction; Theorem 2 alone does not supply one.
* The convex carrier in Theorem 6 is small only when its visible hull or its
  metric entropy is small.  Writing a `d`-dimensional parameter does not by
  itself limit the number of exposed pieces.
* All lower bounds above are for the declared admissible forward family.  For
  one fixed automaton, its actually reachable forward vectors may be much
  smaller, and its response entropy should be computed on that subset.

## 7. Comparison with classical weighted-automata theory (after derivation)

The table `H_L(x,y)=L(xy)` is the weighted Hankel table.  The exact residual
state in Theorem 1 is its row restricted to the declared suffix columns, so
the qualitative exact quotient agrees with the weighted Nerode/derivative
viewpoint and with stable semimodules in the general theory of weighted
automata.  See Droste and Kuske's survey on recognizable series and stable
finitely generated semimodules:

* M. Droste and D. Kuske, [*Weighted automata*](https://www.informatik.uni-leipzig.de/~droste/papers/Droste-Kuske-AutoMathA-neu.pdf).

Over a field, finite Hankel rank characterizes minimal linear realization,
and SVD/AAK methods give approximate realizations in spectral or `ell_2`
norms.  Representative primary sources are:

* B. Balle, P. Panangaden, and D. Precup,
  [*A Canonical Form for Weighted Automata and Applications to Approximate
  Minimization*](https://arxiv.org/abs/1501.06841).
* C. Lacroce et al., [*Optimal Spectral-Norm Approximate Minimization of
  Weighted Finite Automata*](https://doi.org/10.4230/LIPIcs.ICALP.2021.118).

Those results do not imply Theorem 2 or Theorem 3: spectral and average
norms on a field-valued Hankel operator differ from uniform error on a
declared suffix family, and max-plus lacks subtraction.  Indeed, equivalence
questions for tropical weighted automata are substantially more delicate
and can be undecidable over common weight domains; see Almagor, Boker, and
Kupferman, [*What's decidable about weighted automata?*](https://doi.org/10.1016/j.ic.2020.104651).

The support-function carrier in Theorem 6 places the approximation problem
inside convex-function entropy.  Bronshtein's classical theorem gives the
sharper `epsilon^{-d/2}` entropy exponent for the full class of uniformly
bounded Lipschitz convex functions:

* E. M. Bronshtein, [*epsilon-entropy of convex sets and
  functions*](https://www.mathnet.ru/eng/smj/v17/i3/p508), 1976.

The new benchmark-level content here is therefore not the name “weighted
residual.”  It is the query-relative uniform entropy sandwich, the explicit
warning that affine suffix dimension can expose all raw coordinates, and the
sharp composable tropical-aggregate quotient with matching response
rate--distortion.

## 8. Director verdict and strongest next theorem

This benchmark passes the requested test at a meaningful but bounded level.
The theory independently recovers the correct exact contextual quotient;
more importantly, it predicts two strict states that are not boundary tables:

```math
\text{tropical block aggregates}
\quad\hbox{and}\quad
\text{a visible upper-hull carrier}.               \tag{8.1}
```

It also separates three quantities that classical state count conflates:
raw presentation size, exact derivative quotient size, and approximate
uniform response entropy.

The strongest next theorem is a **stable tropical exposure theorem**:

> For a derivative-invariant suffix family, characterize the uniform
> response covering numbers up to constants by a scale-dependent exposed-face
> (fat-shattering) dimension, and determine when the resulting approximate
> quotient admits a nonaccumulating finite transition algebra.

Theorems 2 and 3 are the two sides of this proposed statement, but they do
not yet meet for arbitrary suffix geometry.  Proving their equivalence, or
constructing a family with a genuine gap, would turn the automaton benchmark
from a successful validation into a general law of future-response
compression.

## 9. Audit of the shared-parameter max-affine presentation lemma

After the preceding derivation, I audited the general presentation lemma in
`/home/math/quadra/tmp/bounded_description_maxcut.md`.  The lemma says that a
family

```math
f_\theta(x)=\max_{a\in A_x}\langle a,\theta\rangle
```

with `d` shared real parameters, at most `r` witnesses per query, and
response shapes in a radius-`R` ball has

```math
\log_2\operatorname {Cov}_\delta
=O\left(d\log(qr)+d\log(1+R/\delta)\right),        \tag{9.1}
```

where `q` is the number of queries.  Its proof by comparison-hyperplane
faces and quotient-space volume is sound.  Three qualifications determine
how it applies here.

### 9.1 Forward-vector presentation

For a finite declared suffix set `Y`, `q=|Y|`, the residual is

```math
\rho_p(y)=\max_{i\in[p]}\{p_i+h_y(i)\}.            \tag{9.2}
```

After fixing the common-shift gauge on `p`, this is an affine max-presentation
with effective parameter dimension `p-1`, `p` witnesses per query, and at
most

```math
H\le q\binom p2                                    \tag{9.3}
```

comparison hyperplanes

```math
p_i-p_j=h_y(j)-h_y(i).                             \tag{9.4}
```

Therefore, if all residual *shapes* lie in a radius-`R` ball,

```math
\begin{aligned}
\log_2\operatorname {Cov}_\delta
 \{[\rho_p]:p\in\mathbb R^p\}
\le{}&(p-1)\log_2\!left(4\left(q\binom p2+1\right)\right)\\
&+(p-1)\log_2(1+2R/\delta).                       \tag{9.5}
\end{aligned}
```

This bound allows an unbounded forward-parameter set.  It is complementary
to (2.4), which is sharper when a bounded box `[-B,B]^p` is available, and
to (2.3), which is sharper when the suffix query set itself has a small
projective net.  A useful combined upper bound is the minimum of these three
certificates.

The finite-coefficient-alphabet improvement of the presentation lemma does
**not** remove `q` from (9.5) in general.  Although the normals in (9.4) are
the finitely many `e_i-e_j`, the suffix-dependent offsets on the right can
produce arbitrarily many distinct parallel hyperplanes.  Adjoining a
constant parameter makes the presentation homogeneous but also puts those
arbitrary offsets into the coefficient alphabet.  Thus invoking the
`3^d`-normal argument here without an offset hypothesis would be invalid.

### 9.2 Transition-parameter presentation

There is a second, often stronger application.  Fix an automaton topology
with `m` shared transition-weight parameters `theta`.  For a word `w`, every
run `pi` has an incidence/count vector `a_pi`, and

```math
L_\theta(w)=\max_{\pi\text{ over }w}
              \langle a_\pi,\theta\rangle.         \tag{9.6}
```

The lemma applies with parameter dimension `m`, even when the number of
words and the number of runs per word are exponential.  If each transition
can occur at most once, the `a_pi` are binary and the distinct comparison
normals lie in `{-1,0,1}^m`; the response-shape entropy is then

```math
O\left(m^2+m\log(1+R/\delta)\right).               \tag{9.7}
```

For words of length at most `ell`, count vectors lie in
`{0,...,ell}^m`, giving instead

```math
O\left(m^2\log(2\ell+1)
       +m\log(1+R/\delta)\right).                  \tag{9.8}
```

Fixed initial/final offsets must either be included among the shared
parameters or separately bounded; otherwise the same affine-offset caveat
as in (9.4) applies.  Also, (9.8) is a finite-horizon entropy theorem, not by
itself a finite exact quotient closed under an unbounded number of cycles.

### 9.3 Is this stronger than bit counting?

Yes, under its stated semantic hypotheses.  With arbitrary real weights,
ordinary encoding cardinality is infinite.  Equations (9.5), (9.7), and
(9.8) give finite coarse response entropy without bounding weight precision.
The nontrivial step is that an unbounded parameter domain is cut into only
finitely many optimizer faces, and each face has a bounded response image
that can be covered volumetrically.  This is strictly more than counting
finite encodings.

There are two regimes in which the gain should not be oversold.

1. If the parameter box is already bounded, direct parameter quantization
   can beat the arrangement bound.
2. If “description length” means an unrestricted decoder supplied with `B`
   bits, no semantic conclusion stronger than `2^B` possible outputs is
   available; the max-affine theorem gains force only because it restricts
   the grammar of those outputs.

### 9.4 Collision and unification with this report

The max-affine lemma and Theorem 6 are two sides of the same polyhedral
object.  The arrangement proof fixes the queries and varies shared
parameters, thereby counting normal-fan cells.  The upper-hull proof fixes a
forward vector and varies affine suffix parameters, thereby retaining the
visible support carrier.  This is a genuine collision: the exact
support-function part of Theorem 6 should be viewed as the geometric dual of
the presentation lemma, not as an unrelated mechanism.

The two quantitative bounds are nevertheless different:

```math
\begin{array}{c|c|c}
\text{certificate}&\text{pays for}&\text{forgets}\\
\hline
\text{query-net bound (2.3)}&
  \text{projective metric entropy of suffix vectors}&
  \text{number of optimizer faces}\\
\text{max-affine bound (9.1)}&
  \text{shared parameters and optimizer cells}&
  \text{fine metric geometry among queries}\\
\text{exposure lower bound (2.9)}&
  \text{robust independently readable coordinates}&
  \text{nonexposed parameter directions}
\end{array}                                        \tag{9.9}
```

Taking their minimum/maximum produces a more informative response-complexity
