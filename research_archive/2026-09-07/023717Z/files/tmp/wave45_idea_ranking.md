# Wave 45 idea ranking

Read before selection: committed `README.md`, Wave 44 `Updated frontier`
(ledger §10.97.4), and the early Wave 45 `STEERING.md` refresh.  Strict
positive pressure/high replicas, local hard-column neighbor retention, local
Poincare control of the harmonic load, and monotone deletion are excluded.

## Ranked ideas

1. **Macroscopic hard-column orbit Harnack.**  For the minimizer of
   `h_d+lambda R_2(d)`, use uniform blocks `|U|=k=Theta(n)` in (10.1157)--
   (10.1159).  Prove that a positive fraction of these switches have
   `h_(d^U)-h_d=O(L_0)`, or give a scalable exact-minimizer obstruction.
   Unlike one-vertex retention, this is a global orbit statement and directly
   forces project row.  It must be paired with a scalar-value estimate.

2. **Posterior-mixture endpoint domination.**  Express the fixed-density
   endpoint likelihood as its actual selector/completion mixture and seek a
   nonlocal inequality
   `J_L^2 <= C C_V(1)` through posterior-selector information or phase
   coupling.  This can bridge separated state-space phases and does not use
   the false local Poincare or raw reveal-cost bounds.

3. **Hard row-truncated center degree.**  Work with
   `a(z)=U_m{d_S(z)<=H}` on the project-row class and prove
   `max_z a(z)>=exp(-O(L_0))` by a hard collision/common-center theorem.
   Keep the indicator/clipped deficit throughout; do not introduce a fixed
   positive soft pressure.  Explicitly test pair/triple-empty fibers, which
   rule out uniform Helly but not an averaged high-degree theorem.

4. **Scalar value via a row-weighted incidence partition.**  Study
   `Z_lambda=E_d[U_m(I_d) exp(-lambda R_2(d))]`.  A lower bound
   `Z_lambda>=exp(-O(L_0))` proves (10.1149) at once.  First determine whether
   this abundance statement is already too strong on exact minimizers or
   generic near-conference models; do not confuse it with the existential
   scalar target.

5. **Slack-versus-row dichotomy inside each complement fiber.**  If
   `Q(B_S)-q_n` is large, quantify the Hamming cloud of threshold witnesses
   and its intersection with the project-row set.  If it is small for many
   selectors, extract a near-minimizer stability consequence.  Double
   counting must achieve the stretched-exponential column scale, not merely
   polynomial witness multiplicity.

6. **Tropical phase-crossing accounting.**  Generalize the exact `A_8`
   boundary-layer calculation: represent endpoint phases by competing affine
   exponent lines and charge every global load separation to an endpoint
   selector/completion transition.  Prove endpoint domination for a
   checkable single-crossing or laminar phase class, then test whether actual
   minimizers satisfy it or exhibit multi-crossing obstructions.

7. **Approximate-order projection of harmonic load.**  Attack (10.1084) by
   projecting `L_s` onto a monotone function of the global score and bounding
   the integrated residual from actual completion structure.  This retains
   global covariance cancellation and avoids local gradients; it is useful
   only if the residual reaches the project scale.

8. **Correlated selector-chain hard transport.**  Couple nearby selectors
   while transporting a hard favorable center with accumulated slack, then
   use expansion of the selector chain to obtain global degree.  One-step
   Lipschitz thickening alone gives only a subexponential Johnson ball and is
   insufficient; the needed new input is repeated regeneration or branching
   of compatible centers.

9. **Direct bare-tail counting conditioned on the principal-norm profile.**
   Combine the row-sensitive signed-energy tail with a lower-tail structural
   theorem for `Q(A[S])`, seeking a dependence-sensitive count rather than
   ordinary moments.  Wave 44 shows any fixed-center soft margin is circular,
   so the theorem must act directly on the joint hard event.

10. **Square-root cavity reward after phase decomposition.**  Revisit
    constant shortfall only if the endpoint Gibbs law decomposes into phases
    whose coordinate affinities can be bounded using actual quadratic
    completion data.  Generic cube entropy, star covers, and second moments
    remain excluded; this is ranked last until a concrete minimizer-specific
    phase theorem appears.
