## Simultaneous replacement identity

For a signing A, write the signed deficit

```math
d_(s,x)=Q(A)-s q_A(x),\qquad s in {+1,-1}.
```

If F is ANY set of edges and A^F is obtained by flipping exactly those signs,
then the identity

```math
Q(A^F)-Q(A)
=- min_(s,x) [d_(s,x)+2s sum_(ij in F) a_ij x_i x_j]
```

is exact. Consequently exact global optimality of A implies that the minimum
on the right is nonpositive for every F. This uses all simultaneous edge
replacements, not only one-edge local stability. However, this identity alone
is an equivalent optimality test, not a new structural theorem.

The tempting fractional replacement F with each edge included by amount t
has a strictly positive deterministic bracket for 0<t<1/2:

```math
d_(s,x)+2t s q_A(x) = 2t Q(A)+(1-2t)d_(s,x)>0.
```

Thus the obstruction is precisely discrete rounding of this common descent
direction. Independent rounding has a maximum over exponentially many spin
tests at the original n^(3/2) scale; it cannot be discarded as an O(n) error.
The fact that an exact minimizer is stable under the actual rounded operation
does not supply the missing sign or summable scale in powered aggregation.
