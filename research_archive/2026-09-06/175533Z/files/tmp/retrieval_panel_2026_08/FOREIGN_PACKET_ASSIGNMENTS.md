# Foreign-packet assignments

Each specialist must identify one mechanism foreign to its home field and
decide whether it creates a genuinely new route.  Reports should be concise,
must preserve the original quantifiers, and must say “no transfer” when a
hypothesis fails.

| Home specialist | Foreign packet | Required stress point |
|---|---|---|
| Discrepancy | `toolkits/coding.md`, §§2.2 and 2.5 | Can an arbitrary-root covering localizer or moving stabilizer provide weighted star discrepancy without storing the coset tail? |
| Spin glass | `toolkits/coding.md`, §§2.3 and 2.5 | Can normal-code amalgamation or rooted SDP close deterministic pressure composition while retaining the antipodal channel? |
| Coding | `toolkits/spin_glass.md`, §§2.1, 2.4, 2.15--2.16 | Does overlap interpolation translate to a true all-coset statement, or does disorder averaging reverse the needed quantifier? |
| Banach/tensor | `toolkits/graph_limits.md`, §§2, 3, and 4.8 | Can action compactness or recovery turn a tensor-norm asymptotic into all-order same-spin realization without polarization? |
| Extremal/probabilistic | `toolkits/coding.md`, §§2.3--2.5 | Can amalgamation/covering localizers act as an absorber for a prescribed cut code with `o(n^(3/2))` retouch? |
| Graph limits | `toolkits/coding.md`, §2.5 | Can a growing stabilizer hierarchy define a fluctuation action state with an all-order exact sign recovery theorem? |

For any archive-verified `A/B` proposal, the same run must also address the
verifier's exact objection and return a revised lemma or a withdrawal.
