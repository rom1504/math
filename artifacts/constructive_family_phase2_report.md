# Constructive-family audit, sustained phase 2

This is a subagent proof report for independent audit. It does not update the
project's strategic judgment. Claims are classified individually below.

## 1. Convention and a canonical structured family

Let `r` be an odd prime and write
`GF(r^2)=GF(r)[t]/(t^2-d)`, where `d` is a nonsquare. Let `chi` be the
quadratic character of `GF(r^2)`. The symmetric Paley conference matrix `C`
has coordinates `infinity` and `z in GF(r^2)`, with

```math
C_{\infty,z}=C_{z,\infty}=1,\qquad
C_{z,w}=\chi(z-w)\ (z\ne w),\qquad C_{z,z}=0.
```

Thus `C^2=r^2 I`. For a signing `S` and Boolean vector `y`, use

```math
H_S(y)=\sum_{i<j}S_{ij}y_i y_j=\frac12y^{\mathsf T}Sy,
\qquad \operatorname{cap}(S)=\max_y|H_S(y)|.
```

For every order `n`, let `r(n)` be the least odd prime such that
`N=r(n)^2+1 >= n`. Order the Paley coordinates lexicographically and let
`S_n` be the first `n`-vertex principal restriction. Define the singleton
family

```math
\mathcal F_n=\{S_n\},\qquad
U_n=\operatorname{cap}(S_n),\qquad u_n=U_n^{2/3}.
```

This definition is noncircular: it does not mention `M_n`, a minimizer, or a
bridge search. A matrix is generated by finite-field arithmetic in polynomial
time (apart from evaluating its cap).

## 2. Arbitrary-deletion squeeze

**Proved.** Choose `f:GF(r)->{+1,-1}` with `sum_b f(b)=1`, put
`x_infinity=1`, and put `x_(a+bt)=f(b)`. The character-sum computation already
recorded in the ledger gives `Cx=rx` and hence

```math
H_C(x)=\frac{rN}{2}.                                  \tag{A1}
```

Delete an arbitrary coordinate set `D` of size `d` and call its complement
`K`. Summing the eigenvector equation over `D` gives

```math
rd=\sum_{i\in D}x_i(Cx)_i=2H_{C[D]}(x_D)+x_D^{\mathsf T}C[D,K]x_K.
```

Subtracting the deleted and cross contributions from (A1) proves the exact
identity

```math
H_{C[K]}(x_K)=\frac{rN}{2}-rd+H_{C[D]}(x_D).          \tag{A2}
```

Every principal submatrix of `C` has operator norm at most `r`. Therefore

```math
|H_{C[D]}(x_D)|\le\frac{rd}{2},\qquad
\operatorname{cap}(C[K])\le\frac{r(N-d)}2.
```

Combining these inequalities with (A2), for `n=N-d`, gives

```math
\frac{r(n-2d)}2\le \operatorname{cap}(C[K])\le\frac{rn}{2}. \tag{A3}
```

The lower bound is useful once `d=o(n)`. It applies to **every** deleted set,
not just the canonical one.

Since `r^2=n+d-1`, (A3) implies, uniformly for `d=o(n)`,

```math
U_n=\frac12n^{3/2}+O(d\sqrt n+\sqrt n),
\qquad
u_n=2^{-2/3}n+O(d+1).                                \tag{A4}
```

For the second estimate, apply the mean-value theorem to `t^(2/3)`; (A3)
keeps `U_n` bounded below by a positive constant times `n^(3/2)`.

## 3. Prime-gap input and a summable composition defect

**Imported theorem, primary source identified; mathematical mapping checked.**
Baker, Harman, and Pintz, *The Difference Between Consecutive Primes, II*,
Proc. London Math. Soc. 83 (2001), 532--562, prove that for all sufficiently
large `X`, `[X-X^0.525,X]` contains a prime:

<https://londmathsoc.onlinelibrary.wiley.com/doi/pdf/10.1112/plms/83.3.532>

The standard next-prime consequence is the only imported input used here.
Given large `y`, take `X=y+2y^0.525`. Since
`X^0.525 < 2y^0.525` for all sufficiently large `y`, the theorem supplies a
prime in `[y,X]`. Thus the least prime `r>=y` obeys

```math
r-y=O(y^{0.525}).                                     \tag{A5}
```

Take `y=sqrt(n-1)`. Then

```math
d=r^2+1-n=(r-y)(r+y)=O(n^{0.7625}).                  \tag{A6}
```

Equations (A4)--(A6) prove

```math
u_n=2^{-2/3}n+O(n^{0.7625}).                         \tag{A7}
```

Consequently, for `m,n` sufficiently large,

```math
u_{m+n}\le u_m+u_n+O((m+n)^{0.7625}).               \tag{A8}
```

This defect is geometrically summable because

```math
\sum_{j\ge1}\frac{(2^jk)^{0.7625}}{2^jk}
=O(k^{-0.2375})\longrightarrow0.
```

Thus this explicit singleton family already solves the composition half of
the steering package without constructing a bridge between its children.

## 4. Hidden-equivalence audit: landing is not simplified

**Proved.** The project has constants `0<c_0<C_0` for which
`c_0 n^(3/2)<=M_n<=C_0 n^(3/2)`. If `U_n>=M_n`, the mean-value theorem gives
constants depending only on `c_0,C_0` such that

```math
U_n^{2/3}-M_n^{2/3}=o(n)
\quad\Longleftrightarrow\quad
U_n-M_n=o(n^{3/2}).                                  \tag{A9}
```

By (A4), landing for this family is therefore equivalent to

```math
M_n=\left(\frac12+o(1)\right)n^{3/2}.                \tag{A10}
```

This is stronger than merely proving convergence and is the entire unknown
leading-constant problem. The family is genuinely simpler for composition,
but it supplies no simplification of landing. It should not become the
leading route without an independent lower bound approaching `1/2`.

Equation (A3) also extends the earlier shallow-deletion obstruction: **every**
`o(N)`-vertex restriction of a square-field Paley conference matrix has
normalized cap tending to `1/2`. Any useful Paley landing mechanism must use
a comparable and irregular restriction.

## 5. A comparable-block coset family is rigorously unfavorable

**Proved.** Remove infinity and retain a union of `s` parallel affine lines

```math
L_b=\{a+bt:a\in GF(r)\},\qquad b\in B,quad |B|=s.
```

For nonzero `h in GF(r)`, `chi(h)=1`. For distinct `b,c`, the elementary
quadratic-character sum is

```math
\sum_{h\in GF(r)}\chi(h+(b-c)t)=-1.
```

It follows that all within-line edges have sign `+1`, while the sum of the
`r^2` edge signs between any two lines is `-r`. On spins constant with value
`epsilon_b` on line `L_b`, the energy is exactly

```math
H=\frac r2\left(sr-\left(\sum_{b\in B}\epsilon_b\right)^2\right). \tag{A11}
```

The restriction has order `n=rs` and operator norm at most `r`. Hence

```math
\operatorname{cap}=\frac{r^2s}{2}\quad(s\text{ even}),
```

while for odd `s` its cap lies between `r(sr-1)/2` and `r^2s/2`. If
`s/r -> alpha in (0,1]`, then

```math
\frac{\operatorname{cap}}{(rs)^{3/2}}
\longrightarrow\frac1{2\sqrt\alpha}.               \tag{A12}
```

Thus the natural bounded quotient state given by whole affine lines is
strictly worse than `1/2` at every fixed density below one. A viable
comparable-size Paley restriction cannot be a union of these coarse cosets.

## 6. Pure spectral state does not control cap

**Certified finite exhaustive arithmetic.** Two root-gauged order-8 signings
with internal-edge masks 6875 and 6887 have identical power traces

```text
(tr S^k)_(k=1)^8 = (0,56,0,680,0,10328,0,169544)
```

and hence the same characteristic polynomial

```math
lambda^8-28lambda^6+222lambda^4-620lambda^2+425.
```

Their exact Boolean caps are respectively 14 and 12. Therefore the complete
eigenvalue multiset, and a fortiori any bounded list of spectral moments,
does not determine Boolean cap. A spectral-state family needs an additional
Boolean/restriction invariant; spectral completion alone cannot prove
landing.

## 7. Research judgment and next falsifiable target

The canonical family proves a clean summable composition inequality, but its
landing lemma is exactly the unknown assertion (A10). The line-union theorem
falsifies the simplest comparable-block quotient family, and the order-8
collision falsifies spectrum as a sufficient state.

A materially different candidate must therefore attach a Boolean invariant
to an irregular comparable-size restriction. A concrete falsifiable next
step is to test whether a bounded-depth principal-restriction profile plus a
spectral completion type gives a uniform **upper** bound on all deeper
complement caps. A single scalable pair with the same proposed state but a
linear `2/3`-power cap separation would reject it. Without such a uniform
bound, this proposal remains only a state description and not a landing
mechanism.
