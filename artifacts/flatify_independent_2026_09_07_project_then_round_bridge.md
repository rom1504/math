# Preferred simplification: project an actual bridge, then round the target

Later strengthening: the no-mask, relative-leverage random-gauge proof in
`flatify_adversary_2026_09_07_random_gauge_projector_localization.md`
extends Hadamard localization to r=o(n/log n), with error
O(n^(3/2)(r log n/n)^(1/4)+n). The generic nuclear-target proof below
remains useful for arbitrary bounded-operator actual bridges and can
have a smaller error at very low ranks.

2026-09-07. Independently checked by the construction agent. This removes
the orthogonal rotations and sparse-coordinate localization from the
arbitrary-subspace bridge proof. The projection is applied to the real
target BEFORE the already audited rectangular target-contraction rounding.

Let B be any n-by-n full-sign matrix with ||B||op<=C_0 sqrt(n), where
C_0 is fixed. Let X,Y be prescribed real subspaces of dimensions r_X,r_Y,
and let P_X,P_Y be their orthogonal projections. Put r=r_X+r_Y and

    T=(I-P_X)B(I-P_Y).

Then ||T||op<=C_0 sqrt(n), T annihilates Y, and T^T annihilates X.
Moreover,

    Delta=B-T=P_XB+(I-P_X)BP_Y,
    L=||Delta||_*<=(r_X+r_Y)||B||op<=C_0 r sqrt(n).     (1)

The generic rectangular target-contraction lemma applies: define
ell_i=[sqrt(Delta Delta^T)]_ii and k_j=[sqrt(Delta^T Delta)]_jj,
s_i=(1+ell_i)^(-1/2), t_j=(1+k_j)^(-1/2), M_ij=s_i T_ij t_j.
Then |M_ij|<=1, since

    |T_ij|<=1+sqrt(ell_i k_j)<=sqrt((1+ell_i)(1+k_j)).

Independent mean-M sign rounding produces some full-sign C with

    beta(C-T)<=2C_0 n sqrt(L)+sqrt(8nL u)+(4/3)u,
    u=(2n+2)log 2.                                    (2)

For clarity, the variance is at most4nL, without assuming T is
orthogonal: 1-M_ij^2<=(1-s_i^2t_j^2)+2|Delta_ij|, the first sum is
at most2nL, and sum|Delta_ij|<=nL. The deterministic contraction
error is at most2C_0 n sqrt(L) by the operator bound and
sum(1-s_i)^2,sum(1-t_j)^2<=L. Bernstein and a union over4^n Boolean
pairs give (2) with success probability at least1/2.

Consequently the resulting ACTUAL full-sign bridge satisfies, for
EVERY Boolean x,y,

 |x^T C y|
   <=C_0 sqrt(n)||(I-P_X)x||||(I-P_Y)y||
                         +O_(C_0)(n^(5/4)sqrt(r)+n).  (3)

For a Hadamard B one has C_0=1. No separate O(n sqrt(r)) exceptional
term, no subspace-to-coordinate isometry, and no sign-pattern partition
are required. Rank r=o(sqrt(n)) gives an o(n^(3/2)) error. The zero-rank
case simply keeps B, with zero error.

At arbitrary n, pad to a Hadamard order N=(1+o(1))n, embed X,Y by zeros,
apply (1)--(3) at N, and restrict to original rows/columns. The extended
spins have zero padding and still belong to the real cube, so the same
uniform bilinear bound applies. Their residual norms are exactly the
original ones. Thus the all-order normalization changes by1+o(1), not
by an unspecified child-energy error. The existing dense Hadamard orders
generated by2 and12 provide the padding; no limit for M_n is assumed.

## Gaussian-sign bridges also admit the operation

If vec(B) is the sign of a Gaussian correlation matrix R<=KI, the
Gaussian Holder inequality gives, for every real coefficient array h,

    log E exp<h,B><=K||h||^2/2.

Indeed use scalar Holder exponent K and cosh(Kh_i)<=exp(K^2h_i^2/2).
For fixed Euclidean-unit u,v, u^T Bv is therefore sub-Gaussian with
variance proxy K. A1/4-net on each unit sphere has at most9^n points;
the standard net inequality and a union bound give

    ||B||op<=C sqrt(Kn)

with probability at least1-exp(-c n), for suitable absolute constants.
Thus samples of any bounded-covariance Gaussian-sign bridge can be
projected and recovered as full signs by (1)--(3), uniformly on all
spin pairs. This is a valid way of combining an actual correlated bridge
with a declared low-rank subspace condition.

This does not pay the remaining child-energy versus actual residual
bridge maximum. The independently proved Rademacher residual-width
theorem shows that separately charging the full residual operator norm
cannot suffice for ANY sublinear-rank choice of X,Y, even if a stronger
rounding operation eventually enlarges the rank range in (3).
