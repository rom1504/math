# Antipodal deepest-hole balancing

## Statement under audit

Let \(C\le\mathbb F_2^N\) be linear with \({\bf1}\notin C\), and let

\[
D=C\cup({\bf1}+C)=\operatorname{span}(C,{\bf1}).
\]

For \(a\in\mathbb F_2^N\), put

\[
f(a)=d(a,C),\qquad g(a)=d(a,{\bf1}+C)=f(a+{\bf1}).
\]

The proposed theorem is:

> There is a deepest hole \(a\) of \(D\) such that
> \[
> |f(a)-g(a)|\le1.
> \tag{1}
> \]

This remains unproved in this note, but extensive exact computation found
no counterexample.

## 1. Exact quotient-graph reformulation

Let

\[
\Gamma=\mathbb F_2^N/C
\]

with the cubelike Cayley-graph metric generated by the coordinate
syndromes, and let
\[
w={\bf1}+C\ne0.
\]
For \(v=a+C\),

\[
f(a)=d_\Gamma(v,0),\qquad
g(a)=d_\Gamma(v,w).
\]

Moreover,

\[
\rho(D)=
\max_{v\in\Gamma}
\min\{d_\Gamma(v,0),d_\Gamma(v,w)\}.
\tag{2}
\]

Thus (1) is precisely the following graph statement:

> In a connected cubelike graph, for every nonzero \(w\), some vertex
> farthest from the two-point orbit \(\{0,w\}\) lies on the metric
> bisector
> \[
> |d(v,0)-d(v,w)|\le1.
> \tag{3}
> \]

The translation \(v\mapsto v+w\) interchanges the two distances, so every
deepest coset comes in an antipodal orientation pair.  This symmetry alone
does not prove (3): a geodesic from \(v\) to \(v+w\) may pass through
vertices closer than \(\rho(D)\) to one of the centers.

## 2. Exhaustive and randomized verification

An independent exact program enumerated every binary linear subspace
\(C\) with \({\bf1}\notin C\), computed all distances, and checked all
deepest holes.

Results:

| ambient length \(N\) | eligible codes tested | verdict | largest minimum gap |
|---:|---:|---|---:|
| 1 | 1 | all pass | 1 |
| 2 | 3 | all pass | 1 |
| 3 | 11 | all pass | 1 |
| 4 | 51 | all pass | 1 |
| 5 | 307 | all pass | 1 |
| 6 | 2,451 | all pass | 1 |
| 7 | 26,387 | all pass | 1 |

Here the “minimum gap” for a code is

\[
\min_{\substack{a:\ d(a,D)=\rho(D)}}
|f(a)-g(a)|.
\]

A separate multi-source-BFS implementation tested 300 random linear
codes at each length \(N=8,\ldots,16\), again with no counterexample.

To separate the issue from coding presentations, every connected
cubelike Cayley graph on \(\mathbb F_2^k\) was enumerated for \(k\le4\),
and every nonzero center \(w\) was tested.  At \(k=4\), this covers
468,480 generator-set/center pairs.  All satisfy (3).

At \(k=5\), an optimized independent C implementation exhaustively tested
every connected connection set of size at most seven and then twenty
million pseudorandom connection sets.  In total this checked 715,725,086
connected (connection-set, center) pairs, again with no counterexample.
This is not a complete enumeration of the \(k=5\) connection sets.

The exact audit code is `_antipodal_code_audit.py`.

## 3. Relation to the literature on normal codes

Graham and Sloane introduced, for a binary linear code \(E\) split by a
coordinate into halves \(E_0,E_1\), the coordinate norm

\[
N^{(i)}(E)=\max_x\{d(x,E_0)+d(x,E_1)\}.
\]

A coordinate is acceptable if
\[
N^{(i)}(E)\le2\rho(E)+1,
\]
and a code is normal if it has an acceptable coordinate.  Their
framework is very close to the present two-half distance problem, but it
does not supply the desired theorem:

* normality controls the **maximum** of \(f+g\), while (1) asks only for
  one deepest coset with balanced \(f,g\);
* our index-two split \(D=C\cup({\bf1}+C)\) need not arise by fixing an
  existing Hamming coordinate of \(D\);
* even the broad question whether every binary linear code is normal has
  long been listed as open.

One can realize the split as a coordinate by forming the graph code

\[
\widetilde D=
\{(c,0):c\in C\}
\cup
\{({\bf1}+c,1):c\in C\}.
\]

The new coordinate has
\[
N^{(\mathrm{new})}(\widetilde D)
=1+\max_a(f(a)+g(a)),
\]
but its acceptability would be a stronger global assertion and is not
known automatically.  Thus the normal-code literature validates the
geometric formulation but also warns that a blanket proof from standard
covering-radius theory would resolve a recognized hard phenomenon.

## 4. Local maximality consequence

Suppose \(a\) is a deepest hole with

\[
f(a)=\rho,\qquad g(a)\ge\rho+2.
\]

For every coordinate neighbor \(a+e_i\), Lipschitz continuity gives
\(g(a+e_i)\ge\rho+1\).  Since no point can have distance greater than
\(\rho\) from \(D\), necessarily

\[
f(a+e_i)\le\rho
\qquad\text{for every }i.
\tag{4}
\]

Thus an unbalanced counterexample would force \(a\) to be a local maximum
of the distance to the single half-code \(C\) in every coordinate
direction.  If \(e\in a+C\) is a coset leader of weight \(\rho\), then
for every coordinate outside \(\operatorname{supp}e\), there is a word
of \(a+C\), containing that coordinate, of weight at most \(\rho+1\).
This strong covering-by-near-leaders property is a possible route to a
linear-code proof, but no contradiction has yet been completed.

## 5. Exact translation to the quadratic-form problem

Encode a signing by \(a\in\mathbb F_2^{\binom n2}\), and let \(C\) be the
cut code.  If

\[
P=\max_x H_A(x),\qquad Q=-\min_xH_A(x),
\]

then

\[
P=N-2d(a,C),\qquad
Q=N-2d(a,{\bf1}+C),
\qquad N=\binom n2.
\tag{5}
\]

Minimizing \(\max(P,Q)\) is the same as choosing a deepest hole of \(D\).
Therefore (1) would imply that an optimal signing can be chosen with

\[
\boxed{|P-Q|\le2.}
\tag{6}
\]

Let

\[
R(A)=\frac{\max H_A-\min H_A}{2}=\frac{P+Q}{2}.
\]

Since always \(R(A)\le\max(P,Q)\), (6) would give

\[
\boxed{
\left|
F(n)-\min_A R(A)
\right|\le1.
}
\tag{7}
\]

The half-range has the exact signed-cut-norm interpretation developed
elsewhere and is block-superadditive.  Hence the balancing theorem would
remove the unknown midpoint of the energy range at only \(O(1)\) cost.
It would be a meaningful structural advance, although superadditivity at
the \(n^{3/2}\) scale alone still does not force convergence.

## Status

No counterexample is known after exhaustive code and cubelike-graph
searches described above.  The missing step is a proof of the
two-center bisector-eccentricity theorem for cubelike word metrics, or an
identification of additional cut-code structure needed to make it true.
